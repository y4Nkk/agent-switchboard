# Agent Note: 单页安装引导的步骤说明

Status: implemented

## Problem

安装器说明侧重产品用途与当前状态，没有连续说明确认位置、安装、打开应用的顺序。更新完成后又增加了重启确认，用户需要在执行前知道结束后的选择，并在失败时理解应回到哪一步。

## Decision

沿用 Windows 单页安装器，在正文标题与安装材料之间显示三步说明：确认位置、安装应用或更新、打开或重启应用。每步同时显示已完成、当前步骤、待进行或需处理的文字状态，不仅依赖颜色。

步骤、动作可用性和按钮含义集中由安装器同一视图状态投影，不另存步骤计数或启动偏好。状态区分准备、安装中、安装失败、等待启动、启动中和启动失败。只有成功安装后进入第三步；目录错误回到第一步处理，其他安装失败留在第二步，启动失败留在第三步。失败对象只保留当前这一次真实异常，步骤与诊断共用该对象。当前说明由原摘要拥有，准备状态指导确认位置和点击动作，完成状态解释显式打开或稍后选择，不在步骤条重复长文。

安装重试沿用已验证请求的 Update 身份，不用部分写入的程序文件重新判断首次安装还是更新；目录验证未成功时仍从当前目标读取实际事实。正常启动应用不消费安装器状态，本引导只在实际运行安装包时出现。

中英文文案继续由 InstallerText 唯一拥有。布局沿用安装器字体、行动蓝与正文滚动，底部操作保持可达；不改安装引擎、更新协议或启动参数。

- 已检索活跃笔记，无其他步骤说明的提案或被拒方案，无需归档。

## Alternatives considered

- 只补一段静态操作文字，改动最少且不占步骤条空间；但安装失败和等待重启时不能标明当前所处步骤，因此采用从既有状态投影的三步说明。
- 改成多页的下一步向导，可以逐页聚焦单项任务；但目前只有安装位置一项输入，会增加确认次数，并使自动开始的应用内更新进入不同流程，因此保留单页。

## Consequences

- 首次安装、手动覆盖安装与应用内更新共享三步视图，文案符合实际下一步。
- 安装或打开失败不会被显示为步骤完成，重试沿用原执行入口。
- 旧产品用途摘要被操作说明替换，无第二套步骤状态或兼容入口。
- 代价是步骤条增加正文高度，由原正文滚动容纳中英文与小工作区，底部操作不随正文滚动；不新增布局或动效依赖。

## Verification

执行笔记校验与静态差异、直接引用和文件长度检查；按项目规则不运行编译、类型检查、自动化测试或真实安装。真实 Windows 窗口、屏幕阅读器和显示缩放仍需验收。
