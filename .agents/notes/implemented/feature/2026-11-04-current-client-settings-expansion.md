# Agent Note: 双客户端当前配置目录与结构化权限

Status: implemented

## Problem

客户端目录仍输出 Codex 旧粘贴键和不生效的功能开关，拒绝官方分项审批对象，缺少权限档案冲突保护。Claude 写入会删除仍受官方支持的顶层 effortLevel，输出风格限制为内置枚举；权限、通知、终端、保留时间及模型偏好缺少直接入口。

## Decision

ownership 继续唯一拥有字段、类型、控件、分组和归属。Codex 使用当前粘贴与图片开关，提供通知方式和条件、自动回顾、主题，以及供应商 Ultrafast 和回合结束压缩比例；无效 personality/unified_exec 开关移出目录。approval_policy 接受当前字符串或严格 granular 对象，必需与可省略字段从核心校验器投影到界面；预览与写入共用解析器。存在 default_permissions 或 permissions 档案时阻止混写旧沙箱设置，界面明确显示当前文件的选择和冲突，档案在高级重置中也保留。

Claude 提供权限模式、规则、额外目录、基础沙箱及文件/网络规则，终端编辑、减少动画、手动命令 Shell、保留天数、计划目录、提交和 PR 署名、更新通道。沙箱注明只支持 macOS/Linux/WSL 2。自定义输出风格允许内置选择和自定义名称。顶层 effortLevel 留归宿主或显式片段，不再拒绝或无条件删除；模型默认仍使用 modelSettings，逐模型压缩窗口与强度上限复用同一片段和网关路由映射，不新增模型偏好存储。目录提供模型强度、上限选项与窗口边界，恢复运行参数默认值只移除三个界面拥有的叶子。

新增字段继续经既有哈希绑定预览、备份、确认执行和恢复。自动与显式空字符串、空列表含义分开；原生 attribution=false 在读取和编辑署名叶子时等义展开，连接写入保留原文。对象比较忽略键序，列表保持顺序。原生受管结构严格校验，未知同级内容保持不变。

所有权清单只声明当前片段拥有的叶子：当前类型化字段不会因历史清单被再次覆盖或删除；确认写入时重写两份清单，保留其他声明。应用存储只经现有有完整副本的显式修复入口转换，包括 Codex 键重命名、无效开关移除、共享字段从额外片段移到表单、供应商字段从片段移到参数。仍有效的旧参数 effortLevel 转为同一供应商的原生顶层片段。冲突值和供应商片段内的客户端级设置拒绝推断；错误给出字段与归属，暂存失败不替换原目录。运行时无新旧键双读、双写、回退或隐式存储升级。

## Related decisions

[当前配置契约](2026-10-12-current-client-configuration-contract.md)部分重叠：沿用单一目录、通知和模型片段契约；本篇替代其顶层 effortLevel 一律删除及仅编辑模型默认强度的决定。旧决定的最强理由是统一新模型持久化入口；现行官方作用域说明表明删除宿主有效值超出了这一目的。[存储修复](2026-09-23-provider-store-repair.md)部分重叠：沿用暂存、副本校验和保留原目录，补充当前键与片段所有权的显式转换。会话保留库和其他界面笔记不拥有原生配置，不改变它们。

## Alternatives considered

- 只增加 JSON 文本框：可以最快覆盖全部字段；但无法提供类型化控件、空值语义、平台说明和冲突校验，因此只保留既有高级原文入口。
- 运行时同时读取新旧键：旧数据立即可用；但会产生两个事实来源，改为显式且可恢复的存储修复。
- 全面接管 Codex Beta 权限档案：可以统一两套权限 UI；但自定义档案和组织要求超出已确认建议，当前只识别、展示和阻止混写，保留档案原值。
- 把供应商片段中的新客户端字段自动并入全局：能让更多旧档案自动升级；但会丢失逐档案差异或改变其他供应商的行为，无法证明等义时明确拒绝转换。

## Consequences

目录、前后端、校验、读写、预览、恢复、导入和文档使用同一当前契约；旧路径不再成为活动选项。新增纯文本和隔离临时目录回归用例覆盖结构化审批、沙箱冲突、空署名、规则列表、有效 effortLevel 保留、模型偏好投影、显式存储修复和片段交接，以及前端结构值比较和模型字段重置。

按项目要求，本批未运行编译、类型检查或自动化测试，测试源码不构成通过证据；也未读取或写入真实客户端配置、凭据及应用存储。执行笔记结构检查和改动差异检查，源码审阅覆盖相关直接消费者与字段归属。官方能力随客户端版本变化，配置保存不是运行时支持证明；缓存和速度能力仍取决于供应商。用户级配置不覆盖项目或组织强制设置。
