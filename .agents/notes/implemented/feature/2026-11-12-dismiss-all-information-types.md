# Agent Note: 全部全局信息类型支持清除

Status: implemented

## Problem

全局信息只有 Toast 队列条目带 onDismiss，自动准备结果、设置读取错误、持续操作错误和 busy 条目没有删除入口，也不参与清空。截图中的自动修复成功结果因此无法清除。用户要求所有通知类型都支持单条清除和清空。

## Decision

InformationMessage 的 onDismiss 改为必需字段，列表不再按类型筛选可删除消息。Toast 继续由原队列删除并释放计时器；其余消息只在 GlobalInformation 的挂载寿命内记录当前来源是否被清除，不修改原生快照、错误闸门或正在运行的任务，不写入用户配置。

每类来源只保留当前发生实例及一位清除标志：操作错误按原始对象、设置错误按读取失败的原始对象、准备结果按 sessionId/runId/revision、忙碌状态按连续 busy 周期。来源改变或暂时消失时重置清除状态；翻译、折叠展开和父组件普通重绘不让已清除实例复活。消失后再次出现的相同值仍是新一轮通知。

设置读取失败改由 useAppSettings 保存原始 CommandError；设置页和启动导航仍消费从它派生的当前语言文案，AppShell/GlobalInformation 传递原始错误用于清除实例识别。这样语言切换不会让已清除错误重新出现，也没有第二份错误状态。

Toast 被两条队列上限淘汰时，按加入前后的条目身份清理退出队列者的全部计时状态。清理复用 clearToastTimer，同时移除活动计时、截止时间和暂停剩余时间；不能只遍历活动 timer，因为未占摘要的消息已暂停，淘汰时同样需要释放。

## Related decisions

- [标题栏统一信息](../../implemented/feature/2026-10-12-titlebar-information.md)部分重叠：保留单一信息面、队列、计时及无消息即隐藏；本篇取代仅 Toast 可清除的限制。
- [自动准备](../../implemented/feature/2026-11-11-automatic-application-data-preparation.md)继续拥有修复、备份和可用性；清除结果只改变通知展示，不删除诊断快照或备份。
- 检索命中的后台检测、来源恢复、外框与折叠笔记仍拥有独立职责；无同主题提案需要删除或归档。

## Alternatives considered

- 清除时把业务 error/busy/preparation 一并重置：可直接复用现有状态更新而无展示标志，但会把用户关闭通知误当成故障恢复或任务完成，破坏原领域执行语义。
- 将所有派生消息复制进 Toast 队列：可复用统一删除和计时，但引入快照副本，并受两条队列上限影响；实时状态会失去原有优先级、更新及生命周期。
- 永久保存已清除消息 ID：重启后仍不会看到历史提示，但错误和 busy 的固定 ID 会吞掉未来事件，还增加了用户没有要求的落盘格式与历史集合。

## Verification

- 隔离 Vite 页面直接挂载真实 AppShell/GlobalInformation，来源使用页面内存状态与实际 Toast 队列，不连接真实配置。自动修复 4 个文件的结果出现删除按钮，点击后摘要和弹层消失。
- 设置错误、操作错误、自动修复结果、busy 与 error/warning Toast 共 6 条，每条都有删除按钮，点击清空后入口完全消失；页面同时显示底层 busy 仍为真、持续错误仍存在。
- 清空后同源重绘和中英文切换均不恢复旧消息；结束旧 busy 周期后再次开始、新准备运行修订与 info/success Toast 共 4 条重新显示且都可清除，再次清空有效。新消息从收起状态开始。
- 浏览器控制台 error/warn 为空；截图保留自动修复结果的单条删除与可用清空按钮。覆盖隔离组件行为，不证明安装版或原生窗口焦点恢复。
- 通知队列淘汰清理按加入前的条目与实际保留 ID 核对，活动与暂停计时均由同一个 clearToastTimer 释放；不再只遍历活动 timer。该路径经源码检查，未执行自动化计时测试。
- 源码与直接消费者、差异和笔记门禁按窄范围检查；未运行类型检查、生产构建或自动化测试。

## Consequences

通知行不再存在可清除类型白名单，新增消息必须提供 onDismiss；清空直接处理当前全部条目。普通队列沿用原删除与计时器；非队列来源每类仅保留当前实例与一位清除标志，不积累历史集合，代价是清除状态不跨外壳卸载或重启保留。busy 清除不代表任务结束，持续错误清除不代表功能恢复，写入闸门不受影响。设置加载错误增加原始对象的传递，设置页仍消费同一对象派生的语言文案。
