# Agent Note: 供应商存储改为保留数据的智能修复

Status: implemented

## Problem

供应商存储读取失败时，界面目前只提供清空整个存储的入口。这会删除仍可读取的档案、客户端设置和切换记录，也无法指出具体失败文件。严格契约升级后，缺少新增加的自动设置键就可能触发此错误。

## Decision

全局入口现在是 `repair_application_data`，编排配置目录修复和出口设置修复；配置目录仍由 `ConfigStore::repair` 独占，出口文件由 `outbound_proxy::repair` 独占。返回所有修复文件、备份路径与逐域错误，失败项不抹去其他域已经完成的修复。入口和错误提示统一使用应用数据语义，旧供应商专属 IPC 与 UI 回调删除；真实客户端配置写入边界不变。

存储修复仅处理能证明语义不变的差异：为当前契约缺失的设置意图补上 `automatic`，移除 JSON 文本开头的 BOM，移除 Claude 供应商参数中已退役且值为 `automatic` 的 `effortLevel`，保留其余字段、凭据和历史。`automatic` 从不向客户端写入值，删除这个无值旧项不改变模型选择或推理强度；仍有效的显式顶层强度转入同一供应商的原生片段，不猜测对应模型或降低强度；字段冲突时拒绝替换原目录。先复制完整配置目录到独立暂存位置，在暂存副本上修复并通过现有严格读取器验证；确认原目录未被外部修改后交换目录，旧目录保留为可恢复副本。配置修复器返回修复文件和副本路径，由全局报告汇总；无改动但已有效时返回成功。每个不能安全修复的文件给出相对路径与原因，保持原数据原样。

入口从“清空旧档案并重新开始”改为“一键智能修复”，删除清空命令、删除实现、旧日志动作和相关文案。启动直接初始化当前存储契约，删除永远返回未升级的迁移占位入口；旧布局标记由 `ConfigStore` 一处定义，读取与修复共用。供应商领域修复只触及应用拥有的 `state/configuration/`，全局编排另检查独立的出口设置；绝不写 Codex/Claude Code 的实际配置、凭据和网关路由。旧聚合格式或中断事务不能仅凭猜测转换，须明确报告，不隐藏标记或移走记录。

## Alternatives considered

- **继续保留清空入口作为失败后回退**：能让页面迅速恢复，但会丢失仍可用的供应商数据，与用户的明确要求冲突，放弃。
- **逐文件原地改写**：实现较少，但多文件修复失败时可能只完成一半，无法保证严格读取器接受整个存储，放弃。
- **自动丢弃未知字段或坏档案**：可以绕过严格校验，却无法证明业务含义不变，放弃。

## Consequences

[双客户端当前配置目录与结构化权限](2026-11-04-current-client-settings-expansion.md)补充显式转换的字段范围：Codex 当前键优先、无效开关移除、Claude 类型化字段与片段按现有目录交接。运行时只读当前结构；共享/参数冲突与供应商片段中的客户端级字段拒绝推断。原有暂存、完整校验、原目录副本与失败回滚机制不变。

[当前客户端配置契约](2026-10-12-current-client-configuration-contract.md)补充新字段和值域：缺少自动设置可通过本篇定义的显式修复入口补齐，退役且无值的 Claude 推理参数在同一入口删除。严格运行时读取器继续只接受当前契约，不增加双读或兼容校验；失效类型和审批值不猜测转换；有效顶层推理参数按同字段交接，真实客户端配置仍由确认执行器单独管理。

当前设置键缺失时，一键补齐并保留其他记录；修复前原目录持久保留。前后端不再暴露清空供应商存储命令、日志兼容动作或文案，也没有第二套迁移入口。旧版清空日志行不再被当前日志读取器识别。修复不写真实客户端配置、账号绑定或用量历史，已有档案的含义不变。

完全无法解析的档案及无法推断语义的旧格式不能自动修复；应用给出可定位的错误，保持原数据不变。完整目录副本会增加一次磁盘占用，换来失败时可恢复。代码包含隔离临时目录的修复与拒绝案例。

## Verification

历史验证：桌面端聚焦测试首次被七处已有测试编译错误阻断，未记为通过；[共用 CI 门禁](../process/2026-10-12-shared-ci-gate.md)修正失效测试引用后，四项升级修复回归及完整 Rust 工作区测试通过。独立应用标识及临时应用目录的真实 debug 后端验证，对现有存储的副本调用当时的供应商修复命令：恢复读取 3 个 Codex 和 4 个 Claude 档案、修复 9 个文件，原始目录备份逐字节一致，已有字段完整保留；重复修复零写入，显式旧强度与未知自动字段均拒绝且原文件未变。真实存储在验证前后的全部文件哈希一致。测试资料仅保存在忽略的 `.tmp/` 中，不能提交或发布。本批全局编排仅做源码及接入检查，未重跑上述测试。
