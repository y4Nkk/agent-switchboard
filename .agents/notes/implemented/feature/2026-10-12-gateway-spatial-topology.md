# Agent Note: 本机网关的 2.5D 拓扑与客户端聚焦

Status: implemented

## Problem

本机网关的平面文字节点与长协议芯片挤在同一条连线上，用户需要逐项阅读才能分辨客户端、监听器和上游供应商。未配置网关路由的客户端仍有接入连线，且最近请求无法按客户端查看，容易把未接入或历史流量理解为当前连接。

## Decision

本篇只拥有实际网关连接、状态与流量聚焦。模型配置图与保存应用流程由[图形化模型路由](../architecture/2026-10-26-graphical-model-routing.md)拥有。监听状态、恢复、实际拓扑、运行统计和最近请求在同一总览内依次呈现，已保存方案接续在下方。实际拓扑、统计与最近请求在网关工作区可见且取得快照后挂载，离开时释放图形测量，页面保留客户端筛选。未应用草稿不会被呈现为运行连接。

拓扑采用固定阅读方向的开放 2.5D 设备场景，文字、地址和操作保持正视排版。终端与模型服务采用金属设备 SVG，中央监听器复用总览网关的机身路径，拓扑内设备静止。设备、位置与留白建立层级，场景使用低对比柔光，节点没有常驻卡片边框。曲线箭头区分保持原格式、转换格式和监听失败，端点接入设备的可见接口。复用全局语义色、字体、按钮和 ClientFilter，不引入三维运行时、画布交互或新增依赖。客户端、中央监听器、供应商仍由同一份 gateway_status 快照拥有，协议标签沿用现有本地化函数。

路径端点由设备内的 SVG 接口拥有。拓扑在场景挂载后把元素交给连线层，首次快照即可测量接口的渲染坐标。ResizeObserver 在节点或场景尺寸变化时重新测量，合并到一个动画帧更新 SVG 坐标。观察器及待执行帧随组件卸载或路由变化清理。窄窗口顺序堆叠设备并隐藏跨列连线，请求计数附在所属节点旁。

页面只持有一个临时客户端筛选值。共享筛选器与节点点击共同更新它：聚焦路径同步筛选最近请求，整体仪表保持网关全局统计并明确说明范围。不持久化筛选，不修改任何路由或客户端配置。未接入的客户端不绘制网关连线；节点计数仅纳入近 60 分钟能匹配当前路由的样本。端口预览、确认、监听重试与恢复入口沿用原执行路径。

运行统计以统一图组呈现。组头列出后端本次启动的精准累计请求与失败数，近 60 分钟阶梯图按分钟读取保留样本，启动之前和已被淘汰样本的时间段留空。用时图在同一零基线的时间刻度上标记 P50 与 P95，保持原有状态非空的样本口径。协议环仅统计有上游协议的保留样本，列出数量与占比。统计图与最近请求复用同份快照，只有请求明细随客户端筛选。没有对应样本时显示各图空态。

网关总览居中呈现内联 SVG，图下依次呈现真实状态、地址、端口及操作。`GatewayHub` 使用同一份快照区分设置端口与实际监听端口。装饰画成单台低矮的网关设备，用金属机身、散热格栅和下沉的网络端口建立辨识度。端口内的微光用 CSS 错峰播放，只有网关页面与窗口可见时播放，减少动态效果时呈现完整静止构图。状态文字、灯和错误说明是运行事实的来源。

面向用户的文案由 `gateway` 双语目录拥有，先说明请求去向、网关是否启动以及下一步操作。界面使用「应用」「模型服务」「本机地址」「实际监听端口」「连接配置版本」等说法；请求格式保留共享协议精确名称，并添加格式标签。配置连接、网关就绪和上游请求成功是不同事实：空连接状态说明暂无应用连接，运行状态只说明网关已启动，不承诺模型服务可用；请求结果用成功、失败或未完成配合原状态码显示。错误先呈现可执行指引，原始原因另标「详细原因」，不丢弃诊断信息。更换端口与结束恢复的确认仍说明具体影响及删除范围。

最近请求继续复用共享 Table；网关样式为表格设置 56rem 最小宽度，使用已有容器横向滚动，应用名与结果单元格不换行。较长说明与协议可在所属列换行，避免窄窗口把品牌名和成功、失败结果拆成碎字，不添加模块分割线。

历史决策检索仅命中[协议标签本地化](2026-10-12-gateway-localized-protocol-labels.md)，属于部分重叠：该篇继续拥有协议文案决策，本篇拥有拓扑呈现与聚焦语义，不替换旧篇。

## Alternatives considered

- 原有横向图条布局能节省单项高度，但图条没有共同刻度，长协议条还会单独占一行。阶梯趋势、同轴点图与环形占比分别呈现时间、延迟和组成，并按可用宽度重排。

- 沿用 SVG 外框边缘作为连线端点能复用现有测量。设备缩放后的留白会使线与机身分开，实际接口可以由同一份 SVG 形状提供坐标和可见的接点。

- 独立折叠区能压缩首页并延迟挂载拓扑。查看连接与请求需要重复展开，实际状态也与页首的监听状态分离。总览以同一份快照直接呈现运行信息，并沿用工作区可见性限制拓扑挂载。

- 分体节点能清楚表现连接关系，适合下面的实际运行拓扑。总览装饰以单台网关设备表达页面主题，端口内侧的动效避开真实监听指示灯。
- 在原 PNG 上叠加光效可完整保留参考图材质。光效会依赖固定像素位置，缩放后仍使用原图解析度。内联 SVG 用同一条路径绘制光带与流光，尺寸变化时一同缩放，并交由应用现有的可见性和动效偏好控制。

- 小图与事实横排能缩短页头，但长地址、状态和操作争用同一行。居中插画下的事实与操作区按内容尺寸重排，短窗优先压缩图形。
- 可旋转的 WebGL 三维拓扑能够呈现真实景深与自由视角；本页需要快速读取地址、状态和表格，自由相机增加操作与文字遮挡，且引入无必要的运行时和依赖，因此采用 SVG 设备插图与 CSS 层次。
- 只给现有平面卡片加阴影，改动最小且保留全部布局；但无法区分未接入客户端和当前路由，也不能减少按客户端查请求的步骤，因此同时提供一个共享聚焦状态并移除无路由连线。
- 竖向母线配合卡片框线能稳定对齐多条路径，纯 CSS 的连接也不需要测量；但母线、网格与模块分割线形成过多区域边界，无法满足开放场景的阅读方式，因此使用直接连接设备的 SVG 曲线，并承担尺寸观察与清理责任。
- 把网关运行状态写成「服务可用」、同协议路径写成「原样转发」最简短，读者无需理解技术细节；但本机已启动不能证明上游服务可用，同协议请求也可能经过参数处理，因此只写「已启动」和「保持原格式」，原始状态码与诊断原因仍可读。

## Consequences

- 收益：设备类型、连接方向与监听事实分别有图形及文字承载；聚焦共享 ClientFilter 与页面内唯一状态，用户可从节点直接缩小最近请求范围；没有当前路由的客户端不再伪装接入。
- 代价：SVG 设备占用更多图面高度；曲线增加尺寸观察和帧调度，窄窗口顺序堆叠并隐藏连线。视图不支持自由相机或平移缩放，因为所有状态文字与地址须始终可读。
- GatewayPage 拥有快照读取、临时聚焦与端口弹层。GatewayHub 呈现总览的监听事实，样式在 gateway-overview.css。GatewayTopology 拥有拓扑中央节点、路由和样本归属，GatewayTopologyWires 独占设备端点测量与曲线。GatewayTelemetry 以全量 metrics 计算仪表，最近请求先筛选再截取 20 条。
- 删除旧 GatewayMap、平面卡片节点、线中协议芯片、竖向母线、伪元素连线、底面网格与模块分割线及对应样式，没有并存的旧渲染路径；保留现有协议本地化、配置执行器与端口事务。DESIGN.md 更新为同一事实。
- 布局静态目检覆盖 1080 / 820 / 440 像素内容宽度、浅深主题、监听失败、空路由与聚焦反馈，使用当前源样式与设备 SVG、隔离示例数据，不访问真实配置。宽、中曲线路径未遮挡状态和地址，窄布局没有模块分割线；深色标记底面与中性空设备依据目检修正。文案静态预览覆盖 820 像素监听失败指引和 440 像素请求统计、表格横向滚动，应用品牌名与成功、失败状态可完整读取。静态服务只暴露隔离目录内的示例 HTML、CSS、字体与品牌图标。
- 按项目约定不运行编译、类型检查或自动化测试。静态预览不证明 React 运行时、真实轮询、端口提交或筛选事件正确；这些仍未执行验收。
- 笔记树、格式和归档校验均通过；默认 `npm run verify-notes` 入口因沙盒内 npm 注册表解析失败（ENOTFOUND）未完成，使用本机 Node 离线执行其三个相同脚本通过。差异检查通过，旧拓扑符号与样式无残留源消费者。
- 新总览通过隔离 IPC 数据在实际 React 页面中手动检查。浅色桌面窗口和 1080×640 深色端口冲突场景均可阅读状态和操作，720px 宽的英文窗口中地址单独成行，两个端口并排。完成地址复制、端口变更预览和取消，未提交真实端口更改。
- SVG 装饰通过隔离 IPC 数据在实际 React 页面中手动检查。浅色总览中四个网络端口错峰播放，1080×640 深色窗口缩小画面并按应用的减少动态效果设置关闭动效，浏览器控制台无错误。PNG 运行资源与浏览器夹具的独立 PNG 复制路径已移除。
- 整合后的总览在本地预览使用两条模拟路由和两条请求。首屏数据加载后直接绘制四条连接线，客户端筛选联动拓扑和记录。离开后观察区卸载，返回保留筛选。720px 窗口有数据时只有请求表可横向滚动，空数据时可读到连接与请求空态。
- 重绘后的拓扑在隔离浏览器预览中检查浅色和深色。两条模拟路由的四段曲线均与 SVG 接口坐标对齐，客户端筛选同步淡出对应曲线并筛选请求。模拟监听失败时箭头使用红色虚线，720px 空态保留设备与文字，不绘制接口和连线。
- 新统计图在隔离浏览器中检查了常规流量、512 条保留样本与更大的累计数、零耗时、没有结果或协议的样本、全空和 720px 英文窄窗。累计值与图中样本数各按口径显示，保留记录之前的趋势留空，键盘方向键可查看分钟读数，控制台无错误。
