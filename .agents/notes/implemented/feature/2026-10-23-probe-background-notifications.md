# Agent Note: 雷达后台检测与全局结束通知

Status: implemented

## Problem

检测线程已经独立于页面运行，但当前状态读取和操作挂在 UsageWorkspace，隐藏雷达便停止读取；后端结束批次只写记录，标题栏不知道结果，用户离开页面后无法获知结束或保存失败。短任务可能在两次读取之间结束，不能只观察 running 到 completed。

## Decision

- useSwitchboardModel 唯一持有 useCodexProbe，页面接收同一份状态和操作。运行中及读取失败时每秒读取，不以页面或窗口可见性停止；空闲时停止轮询。
- 原生后端发出 codex-probe-changed 失效事件：批次登记成功、工作线程结束（含运行记录创建或保存失败）和待保存批次的保存重试结束时通知。事件仅携带批次 ID，不携带第二份结果；全局层重新读取 ProbeRegistry 与历史的统一快照。开始命令返回同一批次 ID，前端据此关注该任务。浏览器开发传输沿用显式操作后的刷新及运行时轮询，不虚构原生事件。
- 全局层只关注读取到的运行批次、开始命令返回的批次或后端事件指定的批次；首次已完成历史不通知，首次待保存结果提示错误。新批次即使没有读到 running 也通知，历史删除造成当前批次回落到旧记录不能产生结束通知。完成、取消、失败、配置变化与中断分别表达，视觉题要求人工观察，执行错误或判分未通过不能包装成全部通过。
- 保存失败发送需手动关闭的错误；重试仍失败不重播结束提示，保存成功单独确认。读取及订阅失败通过全局错误提示，订阅失败自动重试；重新获得窗口焦点或可见性立即同步。消息由现有 GlobalInformation 队列唯一显示，沿用隐藏时暂停计时和渲染时翻译，不创建第二份通知历史、系统通知通道或数据库字段。
- 后端截止时间、单批次槽、真实消耗和退出清理保持现有所有权。退出应用仍取消检测，不建立应用外常驻进程。

## Related decisions

活跃笔记按 codex_probe、雷达、后台、全局通知检索。[题库限时与真实检测进度](../../implemented/feature/2026-10-20-probe-deadline-progress.md)部分重叠，继续拥有执行时钟、运行槽和统一快照，仅将页面可见性读取规则改为全局任务读取；[标题栏全局信息](../../implemented/feature/2026-10-12-titlebar-information.md)部分重叠，继续拥有唯一通知队列和展示。其余资源边界、用量与视觉题笔记不改变，无需归档。

## Alternatives considered

- **只把页面轮询改成常开**：改动最少，运行任务可以继续刷新；但工作区未挂载时没有全局所有者，空闲跨入口和后端结束也没有失效信号，因此将所有权提升至全局并由后端发出失效事件。
- **只依赖事件，不读取基线或轮询**：即时且读取量少；但订阅前的任务、网页刷新和丢失事件无法恢复，且实时计时仍需后端快照，因此事件用于失效，统一读取负责状态与恢复。
- **增加持久通知收件箱或系统通知依赖**：能在应用退出后保留通知或由系统弹出；但本需求已有全局标题栏队列，检测退出即取消，新增持久化与权限通道不能改善现有任务生命周期，因此复用当前通知所有者。

## Consequences

- 雷达页面不再创建任务 hook；页面切换与窗口隐藏不停止活动任务读取。
- 后端所有正常工作线程返回路径触发失效，保存失败和重试结束均可重新读取；订阅建立后补读当前快照，封闭初次读取与监听之间的窗口。
- 通知判定覆盖初始历史静默、新批次快速完成、恢复运行后完成、各终态、待保存及重试成功、重复读取不重播。
- 回归测试源码覆盖初始历史静默、历史删除不重播、短任务完成、重复事件、运行重连、不同终态、判分警告、视觉题与待保存重试。开始命令的 Rust、前端类型和浏览器开发派发使用同一返回值，没有保留 void 返回或页面局部任务 hook。
- 已执行前端生产构建（包含类型检查）、全部 34 项前端测试和雷达 Rust 聚焦测试（53 项通过，1 个由上层调用的子进程辅助入口未单独执行）。首次 Rust 编译发现新增 `notify_changed` 函数缺少闭合括号，补齐后聚焦测试与原生应用构建通过。

## Verification limits

`npm run verify-notes` 三项检查与 `git diff --check` 通过。先前并行会话搜索提案的临时链接问题已随该任务落地消失，本次未改动那篇笔记。

原生验证版本以独立应用标识 `dev.agent-switchboard.radar-verification` 构建并在隔离数据目录启动，进入原生启动日志阶段。桌面自动化工具拒绝窗口访问，返回 `Computer Use was not approved to use Agent Switchboard`；用户选择暂不开放访问，仅完成其余验证。因此切页、最小化后继续检测和原生全局通知尚未实测，也未发起真实模型调用。临时凭据副本已移除，原始 `config.toml` 和 `auth.json` 的摘要与验证前一致。

全局状态每秒更新会重新渲染模型消费者，轮询只在活动或失败时持续。事件不替代结果存储；异常退出按既有恢复规则处理。构建和纯逻辑测试不替代原生事件传递、窗口可见性与通知交互的运行时证据。
