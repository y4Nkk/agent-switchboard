# Agent Note: 显式统一 Codex 会话供应商归属

Status: implemented

## Problem

Codex 原生会话列表默认按当前 model_provider 筛选。旧工具创建的 custom、cc-switch、OpenAI 等身份在当前固定 openai 的连接中不会进入默认列表；供应商切换配置已统一身份，既有历史仍需显式整理。普通读取必须继续只读，不能在扫描时悄悄改写会话。

## Decision

会话记录的历史页签在全部或 Codex 范围提供「Codex 会话归属」：先关闭 Codex 桌面与 CLI，预览所有活动、归档及原生登记记录中非 openai 的供应商分组、会话数、原始文件数及数据库行数，再显式确认。该操作只改 threads.model_provider 和原始 JSONL / JSONL.ZST 首条 session_meta 的 model_provider，不改账号、连接、正文、模型、会话身份、时间或归档状态；不使第三方历史成为官方云端会话。

session_manager/provider_transfer 唯一拥有预览、作用域、文件前后哈希、备份与恢复日志。后端解析 CODEX_HOME、sqlite_home 与 CODEX_SQLITE_HOME；前端只提交操作 ID 和确认标志，不能传路径、供应商 ID、SQL 或会话文件内容。预览展示实际数据与索引位置，并列出活动、归档目录之外的登记文件路径。目标身份直接使用既有供应商配置所有者的 CODEX_PROVIDER_ID，不维护另一份常量。原生登记库与可读日志同步处理；原件缺失时明确计数，仅整理已有登记，不重建消息。登记的外部日志需经原生 ID 与元信息核实，目录链接及身份冲突拒绝写入。

写前生成全部原像备份及候选，SQLite 使用原生备份 API 保存一致快照；执行绑定有效期 30 分钟的预览并再次检查来源与进程，SQL 更新在事务内完成，文件在原目录原子替换。持久日志先于原件变更发布，失败恢复已写部分；重启后在同一入口显示待恢复操作。发布临时文件名按操作 ID 派生，写前确认不存在，恢复清理该操作未完成的临时副本。恢复先验证全部文件为原像或后像、供应商为原值或 openai，存在后续修改时停止，保留备份与具体错误。恢复只反向更新供应商列，不用旧数据库覆盖其他新状态。仅最新操作可恢复，历次备份保留在应用状态目录。

客户端启动与安装共用现有互斥所有者，新增 Codex 历史整理用途；期间拒绝新的 Codex 雷达/恢复及安装，阻止普通退出并指向会话工作区；未恢复的中断操作阻止通过 ASB 继续 Codex 会话。不与更新路径混用进程占用策略。历史整理要求关闭当前用户的 Codex 进程，SYSTEM 沙盒服务不因名称前缀被当成用户客户端。

## Related decisions

当前预览由一个原子替换的 preview.json 持有，新预览使旧 ID 失效；[操作日志当前契约](../architecture/2026-11-09-current-operation-journals.md)接管预览清单生命周期。暂存日志必须复核原 ID 与原供应商，数据库备份在原生写入前核对完整摘要及原登记；原目录发布副本在替换前校验完整后像摘要。恢复冲突返回具体文件或登记 ID，原件已经恢复的操作重复请求不再次写入。准备失败在发布恢复日志之前清理自身暂存目录，正式备份继续保留。

[完整本地会话读取](../architecture/2026-10-16-complete-local-session-usage.md)部分重叠：普通读取及原生消息历史继续只读；本篇仅接管用户显式确认的供应商元信息写入例外。原生删除、消息读取、用量和 Claude 保留库的所有权不变，不归档该篇。

[来源静默恢复](../bug-fix/2026-10-29-silent-session-source-recovery.md)部分重叠：复用其当前压缩解码与来源收集，普通读取和自动恢复仍不写原件；本篇的用户确认操作独立拥有写入。Claude 账号保留只消费共享读取约束，与本次元信息整理独立。

## Alternatives considered

- 只改 SQLite：更新快且能立即改变默认列表；但 JSONL 元信息仍保留旧身份，原生重建索引时会再次分组，因此同时更新当前可读原件与登记。
- 只改 JSONL：原始记录成为新身份，客户端以后可重建；但当前 SQLite 仍会按旧身份显示，且分页历史可能没有原始文件，因此必须同步原生登记。
- 改写桌面端列表过滤或自动在供应商切换时重写历史：用户无须单独整理；但前者需要接管外部应用，后者让普通连接切换隐式迁移历史，不采用。显式入口使范围和恢复点可检查。

## Consequences

中英文入口提供范围预览、显式勾选、执行和备份恢复，空结果保持无写入操作。Tauri 命令、开发桥、运行日志和产品文档共同使用此显式契约，不在正常读取或供应商切换时隐式整理旧历史。原生数据库不存在时只处理实际日志，不创建空数据库。

隔离夹具定义普通与压缩日志、数据库和日志混合归属、缺失原件、归档与正文保持、登记外部路径、纯日志来源、过期预览、部分写入恢复、重启后恢复及后续消息或供应商冲突；恢复保留划转后更新的标题。按项目规则仅执行笔记门禁与静态差异检查，夹具、编译和真实历史划转均未执行，源码检查不构成桌面或原生写入验收。

多文件与 SQLite 不能组成单一原子提交，持久恢复日志和前后像校验是恢复边界。原件不可读或身份矛盾时整体停止，不能静默跳过后宣称全部完成。保持归档状态意味着已归档会话仍需在 Codex 归档入口查看。外部客户端随后重新启动或改写记录时，必须重新预览或处理恢复冲突。
