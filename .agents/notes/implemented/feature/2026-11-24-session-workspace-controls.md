# Agent Note: 会话工作区的操作与检索布局

Status: implemented

## Problem

按日期处理在页头，批量操作在结果列表标题旁，两种跨会话管理入口需要分别寻找。项目下拉占用结果列表顶部，搜索和过滤在页头另一行。

## Decision

会话与已归档的页头按客户端筛选、「更多操作」、刷新排列。「更多操作」由共享 ActionMenu 显示图标和文字，收纳批量操作、按日期处理和当前客户端专属项。工作区通过统一的动作入口打开弹窗，批量入口先初始化选择和反馈。搜索加载期间可以进入批量弹窗查看进度。

检索行依次显示项目、搜索和筛选。工作区与批量弹窗复用 SessionSearchControls，项目选择、高度、换行和键盘顺序使用同一布局。结果列表标题显示数量，列表正文提供项目分组、会话结果和分页。

## Alternatives considered

- 保留列表旁的批量入口可以就近发现。批量选择已经在独立弹窗中进行，长期占用列表标题还会使两种批量操作分处两地。
- 把项目也放入筛选弹窗可以缩短主工具栏。项目是会话检索的常用范围，公示当前项目能直接解释列表结果。

## Consequences

- 批量操作增加一次菜单点击，管理入口集中在页头。项目可见性与列表可用高度同时改善，窄容器下检索控件自然换行。
- 项目分组的快捷入口仍作用于对应项目。布局、引用、语法和笔记结构按仓库约定静态检查，桌面弹窗和窄窗口效果仍待运行验收。
