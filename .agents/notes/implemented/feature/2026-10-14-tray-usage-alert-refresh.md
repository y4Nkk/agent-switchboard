# Agent Note: 托盘警示图标与行内用量刷新

Status: implemented

## Problem

托盘行的警示状态原来以文字展示：「查询失败」「待登录」「需重新登录」「上次读数」。文字占据单行余额区的大量宽度（Codex 官方行两个警示词与读数并排就触顶），却不携带任何详情——错误正文只在主界面可见；同时托盘对这些状态没有任何补救动作，用户必须打开主界面才能重试查询。托盘契约原先明确「只读后端同源缓存，不触发查询、凭据刷新」，该约束与「警示无出路」一起成为本次用户主动变更的产品决定。

## Decision

托盘行的警示状态收敛为一个非交互警示图标（`TriangleAlert`），行内不再出现警示文字；[共享 Tooltip](../bug-fix/2026-10-14-tooltip-dismissal-anchor-contract.md) 在供应商行呈现完整读数和警示详情：状态文案、后端错误正文（脚本用量）与上次成功读数时间（`tray.usage.lastReading`，`timeLabel` 绝对时间）。图标旁是该行唯一的用量刷新按钮，仅在警示态存在，调用主界面同一强制查询命令——脚本走 `query_profile_usage`（调度器同一执行器），官方额度走 `query_codex_official_quota`（`quota_refresh::refresh(force = true)`）——两个命令在执行末尾自行发出 `tray-changed`，面板仍只消费共享缓存快照，查询返回值不进渲染层，凭据不出执行器边界。

`.tray-provider` 只拥有轮廓（内边距、描边、悬停底、选中底），切换动作由原生按钮 `.tray-provider-main` 覆盖勾选、名称、用量与状态槽，刷新按钮 `.tray-provider-refresh` 独立其右。按钮不可嵌套是硬约束，两个动作必须是两个真实按钮。展示派生由 `tray-usage.ts` 的 `trayUsageContent` 单点拥有，返回 `{ readings, alert: { title, detail } | null, summary }`；readings 已完成名称、数值、状态色与提示格式化，行组件、正文和测量共用一次派生，在纯函数内用 `tr()` 完成翻译（与 `usage-format.ts` 同一先例）；不保留并行的 `stale` 布尔与 `stateKey` 枚举出口。警示图标以 `data-measure="fixed"` 参与实际用量容器宽度预算，溢出提示同样测量真实宽度；名称、状态和用量的两层排版由[托盘原生玻璃与两层读数布局](2026-10-16-tray-glass-and-reading-layout.md)拥有。`PendingAction` 的 `refresh` 种类沿用单一串行 `run` 队列：刷新进行中图标旋转（`asb-tray-refresh-spin`，遵守两级减少动态偏好），期间面板动作互斥。

DESIGN.md 的托盘行契约（切换槽列序、警示形态、「只读缓存」边界）与官方额度段落的托盘边界已同批改写为新事实。

## Alternatives considered

- 在行按钮内嵌一个可点击的刷新 `<span>` 并用事件拦截区分点击目标，可以不动行结构；但 button 内嵌交互元素是无效 HTML，键盘焦点与读屏语义都会损坏，且正是用户明确要求消除的兼容式 hack，不采用。
- 刷新按钮常驻每个有用量读数的行（不只警示态），可以让健康行也手动刷新；但读数健康时刷新入口与调度器职责重叠，托盘保持最小操作面，警示态按用户要求「警示文案改成刷新按钮」原地转化，不扩大范围。
- 独立实现托盘提示可以单独调整样式和延迟。托盘 WebView 使用桌面应用的共享 Tooltip，沿用统一的锚点和关闭契约。

## Consequences

警示态行获得就地补救：点击刷新即重查，失败仍先写缓存（`record_failure`/官方缓存）再由 `tray-changed` 回流，行提示的警示详情随即更新，同时动作错误经既有 `tray-error` 通道在面板顶部反馈。刷新期间沿用单动作互斥，其他行按钮禁用；官方登录态（待登录/需重新登录）的刷新会重走额度读取并原样返回失败状态，不修复凭据——凭据修复仍只属于主界面。代价：脚本用量「错误但保留读数」的行，行内短标签由「上次读数」变为「查询失败」（详情两条都在悬浮层，信息只增不减）；主按钮的可点击区不再覆盖切换槽右侧的刷新按钮位，警示行右缘点击语义从「整行切换」变为「刷新」。旧 `.tray-usage-state` 文案类、`stale` 布尔与 `data-measure="status"` 测量路径全部删除，无兼容读取。
