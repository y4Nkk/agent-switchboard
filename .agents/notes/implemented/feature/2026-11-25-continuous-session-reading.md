# Agent Note: 单会话连续阅读

Status: implemented

## Problem

单条会话和长消息各有分页控件。读到边界需要停下来翻页，同一条消息的上下文也会被替换。

## Decision

会话详情与收藏正文连续滚动。后端按消息及原文位置分批交付。前端只挂载视口及相邻区域的批次，实测高度用于更新占位。前端相邻批次的读取至多两个同时执行，移出窗口时撤销待执行请求。已执行的请求完成后仅向仍然有效的读取方交付结果。

消息批次以会话消息数和前缀修订绑定同一次阅读。新增末尾消息留待刷新或新定位，已读范围的编辑、移除或重排使旧快照失效。长正文按原始记录及正文摘要验证，后端至多保留一条符合 32 MiB 容量的解码正文与字符分段位置。

查找按消息身份与正文位置定位，即使目标尚未挂载。对话大纲随临近的消息批次加载并直接定位其中的提问。查找与源码匹配仍由[单会话全文查找](2026-11-25-transcript-find.md)拥有。[本地资源边界](../architecture/2026-10-14-bounded-local-resources.md)继续限定每次传输量。

远处正文命中会保持目标分段挂载，等请求结束后用实际标记位置完成滚动。已挂载批次的即时尺寸与历史测量共同决定视口范围。查找展开目标长消息时取消展开动画，避免正文高度变化让分段在定位前退出视口。

## Alternatives considered

- 一次挂载完整文本能保持原生滚动与选择。超长消息会同时放大 IPC 载荷、Markdown 解析和布局成本。
- 触底后追加内容简化了滚动接线。已经读过的内容持续占用 DOM 和内存，大跨度跳转也必须先走过中间批次。

## Consequences

- 单条会话与展开的长正文均可连续滚动。原先的页码输入、前后翻页与复制本页动作已移除，列表结果仍使用共享分页。
- 未测量内容使用估算高度，实际布局完成后滚动条长度会调整。长正文通过原文分段加载，完整复制与导出继续读取原文。

## Verification

2026-11-25 在独立目录运行 153 项 Rust 会话回归、4 项前端读取队列回归和 TypeScript 类型检查。无窗口 Chromium 连接隔离的 Rust 读取器。1501 条合成消息可连续滚到末尾，8 个正文分段都可手动滚过，拼接后与原文逐字符一致。关键词前后跳转、跨分段高亮及隐藏后恢复均已验证。

真实副本抽查 7 条会话，覆盖 Codex 活动、Zstandard 归档、Claude 活动和离线保留，最大样本 8148 条消息。Codex 归档和 Claude 保留各通过一次无窗口滚动验证。调试构建中，首次打开最长用时 66.3 秒，已建索引的尾部读取最长用时 4.2 秒。发布版桌面性能未实测。

## First batch

首次打开先请求最多 25 条真实消息，再建立完整阅读快照。Codex 优先查询已登记的原生线程和消息，其余 Codex 来源复用读取索引里的文件身份反查。Claude 从已提交的保留库按会话读取。首批只提供正文预览，完整定位与操作以阅读快照为准。

全量发现能保证识别未记录过的任意命名续写文件，完整快照继续执行发现。仅凭原生数据库能很快返回正文，但会遗漏只写在原始记录里的内容。为所有旧会话预构建全量索引可省去打开等待，却会增加启动成本并访问用户未打开的会话。

已有快照的消息批次按会话 ID 反查并复核来源身份，再校验快照前缀，滚动不重复扫描全部会话目录。读取索引第 4 版为既有身份条目增加 SQLite [部分索引](https://www.sqlite.org/partialindex.html)和[表达式索引](https://www.sqlite.org/expridx.html)条件，来源只维护一份身份。新建库与第 3 版升级使用同一结构。首批预览若已有滚动位置，完整快照按仍存在的消息 ID 恢复位置。会话内查找在快照就绪后开放。切换会话时新首批读取独立发起，旧快照仍在后台完成，过期结果不会写回当前详情。

从 2,981 个本机历史文件和原生库的隔离副本验证了 7 条真实会话，覆盖 Codex 活动与归档、Claude 活动与保留，最大 8,148 条消息。两个调试构建均从空读取索引开始，最终构建首批后端返回为 16–137 毫秒，尾部批次为 28–259 毫秒，完整快照冷建立最长 33.4 秒。前一次的完整快照冷建立最长 55.8 秒。无窗口 Chromium 在延迟完整读取时先显示 25 条真实消息，并验证切换到完整快照时保留滚动位置，以及旧快照被阻塞期间切换会话后不会显示旧消息。隔离源码副本通过 155 项 Rust 会话回归，未完成的并行用量改动在副本中使用仓库基线。第 3 版真实索引副本的全部 4,885 个派生条目保留，查询计划确认使用会话身份索引。发布版桌面性能未测。
