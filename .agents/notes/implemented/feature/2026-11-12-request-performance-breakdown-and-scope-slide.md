# Agent Note: 请求性能更多指标常显细分与计量范围滑动切换

Status: implemented

## Problem

「请求性能」底部的更多指标藏在共享 CollapsibleSection 里，收起态屏蔽了 Token、时延、失败、重试与客户端覆盖五组事实，展开后才可见；重试与覆盖两组异质数据借用条形图渲染，量纲不同的计数共用同一比例尺，覆盖表的记录时间只能塞在条形注释里。同时生成结果与网络尝试分段切换是瞬时硬切：报告为 null 后直接换成加载态，没有过渡。用户要求：更多指标全部常显、合适处接入表格、分段切换拥有与供应商页 Codex/Claude 切换一致的过渡动画，且无兼容无技术债。

## Decision

更多指标区域常显，不再折叠。`RequestUsageBreakdown`（取代 `RequestUsageDetails`）直接渲染五块内容：Token 用量、请求耗时、失败情况保留条形图；重试事实与模型筛选前的数据来源接入共享 `Table`（来源表列为客户端/记录数/记录时间）；预估费用与记录时间为次级状态行。板块标题用日常说法（请求耗时、失败情况、数据来源、成功比例），不用时延、失败分布、客户端覆盖、观测成功比例等书面词。原 `asb-request-usage-mini-plot`/`extra-*` 类名与折叠状态随契约一并删除。

分段切换动效由 `use-scope-transition` 唯一拥有，镜像 `useClientRouteTransition` 的形态：切换瞬间上一次报告作为退场层渲染（`inert`、`aria-hidden`、`pointer-events: none`、绝对定位不占布局），自目标分段反方向滑出淡出；新范围报告到达后，当前层自分段方位滑入。共用 `lib/slide-motion.ts` 读取 `--asb-motion-fast`/`--asb-space-3`/`--asb-easing`（该模块是滑动动效 token 的唯一读取方，provider hook 同样消费它）。快速切回退场范围时取消退场动画，退场层即卸载；减少动态效果时 token 为 0ms，动画直接跳过。数据钩子不变：退场层只渲染面板自留的上一次报告引用，仅作退出快照，任何时刻不可交互，30 秒轮询与"迟到响应不覆盖新查询"契约原样保留。

## Alternatives considered

- 保留 CollapsibleSection 只是把默认态改为展开：折叠原语的存在本身就是用户要求移除的交互，且五块内容高度稳定，折叠没有省出任何首屏空间。
- 五块全部接入表格：Token、请求耗时、失败情况是同量纲数值的幅度比较，条形图比表格更可读；只有异质计数（重试）和多列事实（数据来源）适合表格。
- 保留两份范围报告常驻、切换时双向交叉滑动（与供应商列表完全同构）：数据钩子的契约是"仅当前查询拥有报表"，为 180ms 动画常驻另一份可交互报告会引入第二条数据保留路径；退场层只需要一个不可交互的只读快照。
- 复用 `useClientRouteTransition` 本体：它绑定 `AppKind` 双端选择器并拥有焦点移交语义，与"同一区域内两份内容换位"不同构；共用的是动效 token（已提取为 `slide-motion`），不是控制器。
- 纯 CSS 过渡类 + 卸载定时器：仓库动效契约是 WAAPI 由动画对象唯一拥有结束与取消、不使用动画事件或计时兜底，CSS 类方案会绕开取消语义。

## Consequences

更多指标永远占据面板尾部高度，性能页纵向变长；五块内容随报告常驻渲染。分段切换期间屏幕上短暂出现上一范围的只读内容（最长 180ms），这是供应商列表同款语义；若新报告在退场结束前未到达，退场结束后显示加载态，切换总时长可能超过 180ms（本地 SQLite 读取通常远快于此）。快速双击切回时内容为加载态而非回滚快照，因为数据钩子会重新读取目标范围。表格列头新增四个消息 key；`usagePerformance.moreStats` 从折叠触发器文案转为板块标题。
