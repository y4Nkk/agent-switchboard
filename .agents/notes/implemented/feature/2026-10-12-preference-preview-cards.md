# Agent Note: 偏好设置预览卡与受控循环演示

Status: implemented

## Problem

偏好设置的多值选项（主题、界面缩放之外，还有关闭行为、动效、启动页面、日志级别）原先全部是文字分段控件。其中「关闭行为」最易误解（点 X 到底退没退出），「减少动效」「日志级别」的档位差异纯靠文字想象。用户要求设置界面尽量以可视化图形呈现，并以 ChatGPT 外观设置为参照。

## Decision

`src/components/AppPreviewCards.tsx` 拥有预览单选卡及行为图示，`preference-preview/WindowScene.tsx` 唯一拥有 400×248 SVG 画布、明暗图示色板、轻量桌面窗口骨架、必要的浮层及主题/缩放图示。每张卡片包含上方图形、下方居中的名称与说明、右上角选中勾号；原生 radio 仍唯一拥有选中、禁用和焦点状态，说明通过 aria-describedby 关联，不增加状态副本。图示使用独立的字面色值，以便浅色、深色和系统主题图始终描绘各自对象；其中侧栏选中底色与图标色直接引用 tokens.css 的固定明暗色板，唯一来源由[侧栏图标状态](2026-10-12-sidebar-icon-states.md)拥有，不再在图示内复制行动蓝及透明度。卡片外观继续消费全局主题令牌，只有托盘示意引用现有 app-icon.svg；窗口使用细灰描边、灰阶标题栏与少量内容，不重复品牌文字和窗口操作图标。

卡组通过 `renderPreview(option.value)` 生成图形，选项只声明值、名称和说明，不再保存一份可能与选项值错配的 JSX 参数。图示直接使用 `api/settings.ts` 的 ThemePreference、MotionPreference、InterfaceScale 等当前契约；WindowScene 从 InterfaceScale 百分值计算缩放系数，表单不维护第二份 90 → 0.9 等对应关系。移除仅做转发的 ThemeModePreview、InterfaceScalePreview，不保留别名、重导出或旧 options.preview 入口。

PreviewCanvas 用同一组宽高声明 SVG 的固有尺寸及 viewBox，CSS 按宽度等比显示，不另定义画布比例；动效行程由图示的起止坐标计算并传给 CSS，样式不再复制图示几何。日志绘图的四行只能使用 RuntimeLogSeverity，静默只作为 RuntimeLogLevel 阈值存在，颜色为穷尽映射，不把未知级别默认为信息色。

- 主题：浅色 / `clipPath` 对半系统 / 深色三张窗口图。
- 界面缩放：固定窗口中的 Aa 字样、文字行和按钮按真实百分值同比缩放，图标标记同比放大，位置固定；最大 125% 档的内容仍完整显示。不叠加重复内容与蓝色包围框，每档说明表达空间与可读性的取舍。
- 关闭行为：淡化窗口以细灰箭头连接到带应用标记的简短托盘浮层（后台运行），与淡化窗口前的细线关机符号（结束运行）对比；退出不使用错误红，正常退出不是故障。
- 减少动效：轻量前景浮层中的同一轨道与行动蓝光点——「跟随系统」卡往返运动，「减少」卡静止并配暂停条。浮层只使用浅灰描边和轻阴影。
- 启动页面：首项高亮及简化的 Codex / Claude Code 供应商列表表达固定入口；另一张以中性导航加返回箭头与时钟表达上次访问，不高亮具体导航项，不再叠加放大的导航图标与时钟浮层。
- 日志级别：直接在窗口内呈现 debug/info/warn/error 四行，按阈值逐级移除并保留行的纵向位置；静默显示斜线圆环及无输出横线。级别色沿用运行日志语义（debug=行动蓝、warn=警告橙、error=错误红、info=中性），双语卡片说明明确每档记录范围，不叠加第二层日志窗口。

界面语言与开关类偏好保持文字控件：语言的选项文字本身就是内容，开关语义已清晰，强行图形化是装饰不是信息。

`base/preference-previews.css` 唯一拥有预览行、卡片布局、状态与演示动画，`base.css` 直接导入；`app-settings.css` 只拥有普通设置结构，不留旧预览规则或补偿覆盖。预览行始终为单列，窄容器规则只改变文字段控件、字体选择器和快捷键的布局，不重置全部设置行。卡片的选中态与禁用态直接由原生 radio 的 `:checked` / `:disabled` 派生，不保留第二份选中 class 或禁用标记；禁用时弱化卡片、显示不可用光标并关闭悬停强调。

卡片保留「界面示意、底部标题」构图，以用户指定的简洁 Apple 风格收敛细节。卡组最大 720px、间距 24px，按选项数最多三列，四档缩放使用两列；列数由现有 options.length 派生为局部 CSS 变量，不属于偏好状态。设置容器小于等于 760px 时两列，小于等于 560px 时单列、最大 360px。卡面使用已有 24px 圆角令牌和统一实体底色，图面与标题区自然衔接；选中只显示单层 2px 蓝色描边及 20px 勾号，15px 标题保持正文色，不叠加内描边。图面比例仅由 SVG 固有宽高决定，窗口下缘允许裁切，实际设置相关内容保持完整。仅关闭行为和动效保留轻阴影浮层，真实卡面不叠加装饰阴影。每卡仍常显一条说明；这部分补充[文案密度收敛](../simplification/2026-10-13-ui-copy-density-reduction.md)的默认一行规则，不恢复重复的设置行副标题。偏好设置大组沿用单层浅灰背景、24px 圆角与 32px 组间留白。`DESIGN.md` 拥有视觉事实。

### 受控循环演示

「跟随系统」动效卡是应用唯一的循环演示动画，构成对「不使用循环装饰动画」设计禁例的受控例外——循环本身就是选项含义，不是装饰。冻结规则镜像动效令牌的两条归零条件（`prefers-reduced-motion` 且跟随系统、显式 reduce 偏好），应用处于减少动态效果时两卡一致静止；该静止本身就是 reduce 模式的诚实写照。禁例本体不改，例外仅由此卡持有。

## Alternatives considered

- **继续使用粗设备边框和图内蓝色包围框**：目标区域最容易定位，也最接近参考图的突出手法；但窗口品牌、内部描边与外部选中态会争抢注意力。轻窗框、灰阶辅助内容与单一功能主体更符合当前明确的简洁 Apple 风格。
- **保留 186px 紧凑缩略卡，仅精修路径**：页面最紧凑、改动最少；但无法体现用户指定参考图的大图与局部突出构图，因此改为两列展示卡并保留常显说明。
- **继续让每个选项携带完整 JSX 图形**：调用直观，也能自由替换每张插图；但图形参数与真实选项值可以错配、缩放值需要重复换算。直接按选项值绘图满足当前六类预览，不引入注册表、独立状态或兼容接口。
- **全部偏好图形化（含语言、开关、快捷键）**：一致性最强、最「彻底」；但语言的图形无增益（选项文字即内容）、开关画图沦为装饰、快捷键已是交互式录入控件，违反「配置事实优先于装饰」的首要设计优先级。否。
- **动效预览用两帧 GIF/逐帧 SMIL 而非 CSS transform 循环**：实现一次播放看似克制；但选项对比需要持续可感知，一次性动画在用户看卡时已播完，演示失效。CSS transform 循环可被两条 reduce 条件精确冻结。否。
- **日志级别用文字 + 色点（不裁剪行）**：更省绘制；但「按阈值裁剪」才是运行时过滤器的真实行为，全行展示会暗示「日志都会被记录只是着色」。裁剪阶梯是唯一诚实表达。否。
- **保留通用窄屏重置，再提高预览行选择器优先级**：改动最少，但会保留一条无必要的布局重置和一条补偿覆盖；删除重置即可让普通行继承原布局、预览行继承单列布局，因此不增加覆盖分支。
- **直接复制参考图中的手机外壳与业务内容**：构图与参考最接近；但会暗示本应用存在手机端和聊天功能。改用本应用桌面窗口、导航与供应商内容，保留参考的画面层次。
- **扩大缩放预览的裁剪区域**：可以露出放大后的全部形状，但会让内容侵入窗框和画布边缘。固定结构、为最大比例预留内容空间，才能同时表达窗口上下文和控件同比缩放。

## Consequences

- 收益：六个多值偏好使用同一套安静的窗口示意，去除粗黑边框、重复品牌、图内蓝色描边和无必要的浮层；主题可在一行比较，四档缩放保持两行；原生单选控件继续拥有键盘与读屏语义。
- 代价：示意图不再复刻完整窗口细节，缩放差异依赖内容尺寸和文字说明；窄容器仍需要更多纵向空间；循环演示例外继续遵守系统及显式减少动效偏好。
- 验证包括差异检查、旧尺寸与直接消费者检索及笔记结构校验 `npm run verify-notes`。实屏继续使用 `.tmp/preferences-preview-20261110/` 内的独立应用标识、应用数据、客户端目录和缓存，Vite 当前页面连接此前离线构建成功的隔离原生后端。本轮精简布局在 1180×780 桌面尺寸下呈现三列主题、两列缩放，在 630×780 窄窗口下全部转为单列且无横向溢出，浏览器控制台没有错误；截图为该目录 `screenshots/apple-theme.jpg`、`apple-window-tray.jpg` 和 `apple-compact.jpg`。既有隔离验证已覆盖「减少动态效果」选择写入 `state/settings.json` 并刷新保留；本轮纯视觉修改不改变该读写契约，未重新构建原生端或运行类型检查、自动化测试。英文、深色宿主、键盘焦点、保存期间禁用、日志阈值及原生 WebView 实屏仍未逐项验收。
