# Agent Note: 会话日期区间归档、恢复与删除

Status: implemented

## Problem

日期筛选只有当前页批量选择，不能处理整个日期区间；没有归档及恢复视图。Claude 截止日期清理是另一套日期和执行契约，无法覆盖两端或已归档记录。

## Decision

保留现有会话/收藏工作区，增加已归档页签。历史与归档页在当前客户端筛选下共用按日期处理弹窗；选择起止日期及归档/恢复/删除，后端扫描完整范围、去重并预览全部对象，不使用分页结果。日期由本机日界转换为包含起日、排除结束次日的 RFC3339 边界。操作覆盖当前客户端、列表状态和全部项目，不受搜索或标签限制，界面明确范围。

预览由应用内唯一 RangeOperations 持有，绑定应用状态根、操作、区间、每条来源内容指纹及明确列出的关联会话。新预览和取消使旧 ID 失效；执行只消费该清单，不在确认时扩大范围；会话或关联范围变化拒绝过期预览。删除复用唯一 delete_source 协调链，不增加删除 SQL 或直接删除 Codex 文件的分支。删除父会话前把原生或保留库会连带处理的子会话列为关联对象，包括区间外对象，确认文案明确说明。失败独立报告；已完成项不会重试，保留项重新预览后操作。

Codex 归档、恢复、删除共用受固定 CODEX_HOME/sqlite_home、客户端租约及供应商恢复状态保护的原生命令创建入口；归档状态仅由原生登记和原件位置拥有。Claude 归档状态由专属 archive.sqlite3 单表拥有，保存应用内归档标记，不移动或修改客户端原文；不改变现有保留库与整理库结构。会话删除同步清理该标记，收藏继续独立保留。应用存续期间保留真实批量进度，执行期间阻止正常退出；异常退出后不自动继续不可恢复操作。

旧 SessionPurgeDialog、cutoff 命令/API、后端 cutoff 删除分支及不再适用的测试和文案一并移除；数据库空间回收继续由保留库所有者完成。

SessionSource 的 archived 仅属于读取模型，不向持久化的 SessionMeta 增加字段；搜索请求必须明确传 archived，get_session_metadata 返回会话及其列表位置，收藏定位据此进入正确页签。Claude 归档库只有 session_id 集合，沿用现有保留库与整理库，没有旧结构双读或写入迁移。进度携带当前预览 ID；读取需传同一 ID，不匹配不返回其他操作的结果，缺少 ID 明确拒绝。

可读父链与连带处理关系分开：parent_session_id 保留 fork 与子代理的导航关系，spawn_parent 只记录真正的 Codex thread_spawn 归属。原生登记从 source 读取，未登记原件通过共用元信息读取器及派生缓存读取；不改变 SessionIdentity 的已保存结构。区间外独立 fork 不加入归档或删除清单。预览的磁盘读取不持有操作状态锁，进度与退出判断不会等待整段扫描。

原生命令复用 [Codex 会话命令](https://github.com/openai/codex/blob/rust-v0.155.0/codex-rs/tui/src/session_archive_commands.rs)。实测原生恢复会更新 updated_at，日期筛选继续采用这一真实最近活动时间，界面明确说明，不另存原日期或改写原生时间。预览后焦点回到范围说明，保持日期及数量可见且支持 Escape 取消；结果与预览每页最多渲染 25 行。

## Alternatives considered

- 在前端翻页后拼接 ID 最易复用现有按钮；但分页变化会遗漏或纳入未确认记录，也不能证明关联删除范围，因此由后端冻结完整清单。
- 确认时重算日期范围能容忍无关会话变化，无需保存完整快照；但会纳入未预览的新对象。逐条内容与来源上下文指纹仅约束已确认身份，既不扩大清单，也不因无关新增而失效。
- 两端都仅保存应用隐藏标记可减少客户端依赖；但 Codex 已有明确原生归档状态，重复标记会成为第二个事实来源，因此 Codex 使用原生命令，Claude 使用应用归档。
- 把归档解释为导出压缩包可释放源空间；但会引入导入、恢复及附件格式契约，偏离当前会话管理中的可恢复归档，因此本功能保留原件。
- 保留旧截止日期清理入口方便旧使用习惯；但两套日期边界与确认流程继续分叉，因此由统一日期区间操作取代。

## Verification

当前工作区和隔离快照的前端构建（含 TypeScript）与 Tauri 原生构建均通过，保留已有 bundle 大小和 Rust 未使用代码警告。隔离快照的会话模块 149 项测试通过、0 失败、1 个由黑盒父测试启动的驱动保持忽略；新增区间用例覆盖跨页、日期边界、来源变化、关联范围变化、独立 fork、取消、持久归档、逐项失败和收藏保留，另外保留原件同长改写及未捕获子会话保护测试。验收快照会话业务文件与工作区一致，入口排除并行的原生遥测改动并保留本次注册和退出保护；没有宣称全仓测试或遥测运行时验收通过。工作区构建发现的原生遥测命令错误参数补齐 to_string 转换，其余并行实现保留。

浏览器连接真实 Tauri 开发后端与当前官方 CLI，九种页签/客户端组合、无效日期、完整预览取消、跨页归档和恢复、预览后新增独立会话保护、内容变化拒绝、区间外子会话、锁文件后的部分失败及重试均通过。追加 26 条会话复核大清单焦点、归档/恢复/删除和进度 ID 隔离；再以两组父会话、真实子代理及独立 fork 验证范围，实际归档、恢复期间区间外 fork 保持活跃且原文不变，完成后按明确测试 ID 清理。共 114 条夹具中 111 条按确认范围删除，3 条哨兵保留，5 个保护文件哈希不变，2 条收藏可阅读，刷新后状态正确，页面 JavaScript 异常为 0。

证据位于 `.tmp/session-range-20261110-VFfE9K/ACCEPTANCE.md`、browser-range.json、final-smoke.json、rust-final.log 与相关截图；全部会话、配置、应用状态及虚构凭据均在该隔离目录，不对真实会话执行操作。原生 WebView2 画面与其他平台没有直接自动化验收。

## Consequences

Codex 操作依赖当前 CLI 支持，顺序处理大批会话可能耗时，界面持续显示真实进度；占用、引用冲突和缺失来源保留具体错误。Claude 归档只影响应用列表，归档保留内容，不以归档代替磁盘回收。批量不是跨客户端事务，逐项结果明确表示部分成功；进程异常结束后已完成的原生操作保持生效，重新预览剩余范围，不自动继续删除。旧 cutoff 流程、旧请求与无身份的进度读取不再接受，没有兼容别名或第二套 Codex 写入路径。
