# Agent Note: 侧栏图标按当前页切换线框与实心

Status: implemented

## Problem

侧栏当前仅通过文字色和按钮底色表达当前页，六个图标始终保持 Lucide 线框形态。用户提供的 Codex 侧栏参考同时使用实心当前页图标、灰色非当前页线框与淡色圆角选中底，要求侧栏采用相同的状态区分。

## Decision

导航图标使用 `@phosphor-icons/react` 的同语义 `regular` / `fill` 配对图形。共享 `src/components/icons.tsx` 直接导出六个语义绑定，按图标模块路径导入；`SideNav` 通过现有 `active` 值同时生成 `aria-current` 与图标 `weight`，不增加状态。非当前页使用灰色线框和透明底，悬停只改变底色与颜色，当前页使用品牌蓝实心图形与常驻浅蓝紫圆角底，文字使用主题正文色并加粗；键盘焦点继续由共享按钮与 Tooltip 承载。图标隐藏于可访问树，按钮名称仍由本地化页名提供。

`tokens.css` 唯一拥有侧栏浅色、深色两份固定色板：蓝紫两端颜色与图标色各定义一次，当前主题角色变量只选择色板，`--asb-sidebar-selected` 只声明一次渐变。浅色底为蓝色 14% 到紫色 9%，图标 #3279F6；深色底为蓝色 24% 到紫色 18%，图标 #8DB4FF。系统深色与显式深色入口只映射到同一份深色色板，不复制颜色或渐变，不复用供应商列表的选中底色。展开和收起共用 `shell.css` 的当前页选择器，保留原有宽度、圆角、图标尺寸和页面状态。

`aria-current="page"` 唯一决定常驻选中底色、品牌蓝与加粗文字，图标实心同样只来自当前页事实。`:active` 仅提供与悬停一致的中性按下反馈，不在导航完成之前冒充当前页；键盘焦点沿用共享焦点环。设置页 `WindowFrame` 的导航缩略图直接消费固定明暗色板，用唯一 SVG 渐变 ID 绘制相同的蓝紫底与品牌蓝图标，不再用行动蓝及固定透明度另画一份侧栏。[偏好预览笔记](2026-10-12-preference-preview-cards.md)继续拥有其余图示色板、画布与几何。

六个语义绑定对应 `ArrowsLeftRightIcon`、`SlidersHorizontalIcon`、`PuzzlePieceIcon`、`ChatsIcon`、`ChartBarIcon`、`GearSixIcon`。原有侧栏布局、对齐与滚动归[桌面工作区](../architecture/2026-10-13-desktop-workspace-uiux.md)所有，其他按钮图标继续使用既有 Lucide 绑定。新增依赖只为提供完整的线框与实心家族，不引入自绘路径或通用图标注册层；导航专用旧 Lucide 绑定删除，其他用量按钮仍使用原有 `UsageIcon`，导航使用支持配对形态的 `UsageNavigationIcon`。

## Alternatives considered

- **在 Lucide SVG 上直接设置 `fill: currentColor`**：不用增加依赖，部分闭合轮廓能获得实心效果；但箭头、滑杆和柱图包含开放路径，无法统一得到有正确留白的实心图形，会使不同入口的选中效果不一致。
- **只加深颜色或描边**：改动最少且能增强对比；但不提供参考截图中实心与线框的形态差异。
- **手绘配对实心图标**：能够逐个控制留白和轮廓；但用户已要求开源库实现，维护第二套路径违背这一方向，官方配对图形已能覆盖需求。
- **让按下态复用当前页样式**：鼠标按下即可看到更强反馈；但按下尚未完成导航，可能同时出现两个蓝色选中项，并让线框与底色表达不同事实。按下只使用中性反馈，常驻选中以 aria-current 为准。
- **为系统深色、显式深色和设置预览分别写颜色**：每处改动直观，图示可独立描绘主题；但同一品牌色和渐变会形成三份事实。固定色板由 tokens.css 拥有，主题入口只映射角色，图示只引用目标主题的固定色值。

## Consequences

- 当前页在颜色、图形和底色三个层次可辨，深色主题使用对应的侧栏品牌蓝变量与实心图形，正文颜色按主题独立适配，状态只有一个当前页来源；无需维护手绘实心路径。
- 固定色板与当前主题角色分离是为了同时服务真实界面和独立明暗预览；这不是旧格式兼容或回退分支。继续使用现有 CSS 变量与主题入口，不增加主题状态、监听器、依赖或 WebView 能力要求。
- 增加一个图标依赖，清单与锁文件同步；用按图标模块导入避免根入口预处理整个图标目录。普通控件与导航分属 Lucide 与 Phosphor 两个既定视觉用途。
- 当前隔离样式预览直接使用实际 tokens.css、shell.css 和六个 Phosphor 图形，人工覆盖浅色／深色与展开／收起四种组合，并在隔离 DOM 中切换至底部设置项。浏览器计算样式确认浅色图标 rgb(50, 121, 246)、正文 rgb(20, 22, 27)，深色图标 rgb(141, 180, 255)、正文 rgb(237, 240, 247)，选中文字字重均为 600。展开与收起实测轨宽为 224px／56px，图标和收起按钮中心均为轨内 28px，收起选中项宽 40px，切换后只有一个 aria-current 当前项。
- 隔离预览只覆盖共享样式和图标，不证明 Tauri 原生毛玻璃、真实页面导航或 Tooltip 行为；设置缩略图的共享色板和 SVG ID 接线仅作源码核对。差异、引用和笔记结构按窄范围检查，编译、类型检查及自动化测试遵循仓库的显式授权规则。
