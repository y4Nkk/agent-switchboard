# Agent Note: 单会话全文查找与定位

Status: implemented

## Problem

会话列表能跨会话搜索。阅读一条长会话时，需要遍历所有关键词命中并定位原文。

## Decision

会话详情中的查找按消息顺序和正文位置遍历不重叠的命中。命中使用稳定消息 ID 定位，并核对正文摘要后按原文字符范围高亮。范围跨读取分段时，每段高亮其中的可见部分。定位的渲染和滚动交给[单会话连续阅读](2026-11-25-continuous-session-reading.md)。

会话列表和单会话查找共用[可取消搜索任务](../bug-fix/2026-10-23-session-search-lifecycle.md)和文本匹配器。两个请求范围以明确的 IPC 标签区分。会话列表继续消费每条消息的首个命中，单会话按客户端与会话 ID 定位同一条时间线，每批传输至多 100 处命中并报告总数。正文位置、读取问题或命中总数变化时，旧的命中窗口失效。查找关闭、会话切换或详情隐藏时取消任务。

## Related decisions

- [会话即时搜索](2026-11-24-live-session-search.md)拥有列表查询和筛选，详情复用其输入法与停顿触发规则。
- [会话读取索引](../architecture/2026-10-22-incremental-session-read-index.md)拥有定位与读取，详情查找消费同一索引。列表仍复用最近查询的派生摘要。
- [本地资源边界](../architecture/2026-10-14-bounded-local-resources.md)继续约束每次消息和正文读取。

## Alternatives considered

- 浏览器页内查找对已渲染文本响应快。消息已折叠或位于其他页时，浏览器无法访问相应正文。

## Consequences

- 逐个查找命中时自动展开并定位到目标消息的原文位置。
- 首次检索及跨命中窗口时顺序扫描当前会话，后台任务提供真实消息进度与取消。结果与定位范围有界，命中数据无需新增持久化结构。
- 命中正文按原始文本显示，Markdown 标记、空白与已截断的分段仍有准确位置。

## Verification

回归用例覆盖重复命中、Unicode 字符偏移、跨正文分段和失效的命中窗口。按项目验证规则，本次执行笔记结构与差异检查。编译、自动化用例及桌面端交互仍待运行。
