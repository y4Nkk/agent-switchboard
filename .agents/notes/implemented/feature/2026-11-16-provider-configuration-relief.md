# Agent Note: 以预设和模型目录减轻供应商配置负担

Status: implemented

## Problem

供应商表单让用户重复选择客户端、声明供应商和模型两层能力，并为每个模型操作八档推理复选框。未知模型会被填入通用窗口和输出上限，掩盖缺失信息。完整显示高级设置的既有决定仍成立，减负必须减少人工判断而不是增加折叠。

## Decision

应用内置可追溯、生成的供应商与模型目录快照。准确匹配端点才补全该供应商的模型信息，不按同名模型跨中转站猜测。预设带入名称、官网、协议及已知参数；用户明确填写的配置保持优先。目录是新建时的输入建议，保存后的具体档案继续是运行时事实，不增加持久化第二来源或兼容格式。

移除表单内重复的客户端选择。新建保留明确的官方登录入口。模型目录使用直接编辑，选择主模型即建立目录条目。删除无依据的通用限制和全推理档位默认值。模型能力只有一处编辑，供应商同名总能力从模型条目汇总；独立协议操作和 Chat 转换配置保留真实含义，以值编辑取代复选矩阵。用途保留原生默认、Primary、固定供应商及 Fable 继承语义，[用途路由卡片](2026-11-23-visual-purpose-routing-cards.md)拥有呈现和编辑方式。运行参数完整显示当前值、来源及修改入口，不要求逐项选择模式。

共享一个草稿、一个保存入口，保存不启用。转换种子保留未知限制、能力审核及来源快照，不把新建目录建议自动套到转换或已有显式值上。模型目录读取、准备和保存的过期响应保护继续有效。

精准检索的其他协议、诊断、布局和资源笔记没有被本决定完全取代，不归档。

## Alternatives considered

- 只调整布局和默认值能保留全部已有契约且成本最低，但用户仍需维护两层能力与模型矩阵，不能满足减负目标。
- 实时拉取目录并自动探测可覆盖更多未知服务，但增加打开编辑器的联网依赖和可能计费的请求，普通请求成功也不能证明全部能力，因此使用内置目录及明确的手动联网入口。
- 为表单增加基础和专家模式能减少首屏控件，但引入另一轮选择和并行编辑表面，因此保持全部信息可见，只在主动修改时呈现值控件。

## Verification

导入脚本校验常用服务商与模型身份，并记录本地输入的 SHA-256；限额只保留正的安全整数。目录缺少推理档位或当前 Chat 适配器没有明确方言时，不自动启用推理控制。

回归用例覆盖完整地址、协议隔离、未知限制、模型添加、已存值和独立操作保留，以及路由 OPTIONS 声明和连接变更后的证据失效。转换界面夹具覆盖审核和原有必填字段。按仓库要求不运行编译、类型检查或自动化测试；执行笔记校验、差异检查与相关源码及直接消费者审查，不据此宣称原生或真实上游验收。

## Consequences

已知端点和模型无需逐项勾选即可完成新建；未知端点不借用同名模型能力；缺失的必需限制明确阻止提交。已保存值和转换待核对状态保持。Codex、Claude、官方表单、模型用途、运行参数、直接消费者和双语文案同步，旧图形编辑模块、原始模型文本、复选矩阵、通用限制及其样式和失效文案移除。没有新增兼容或过渡格式，不修改真实档案或凭据。

目录快照随版本维护，可能滞后；界面标明日期和当前值是否与目录建议一致，不把数值相同冒充可追溯的历史来源。模型声明不等于上游或账号验收，只有明确支持的档位和适配器可自动带入；未知配置仍需集中补齐实际限制，并保留完整直接修正入口。公开目录读取不发送凭据；打开编辑器不联网，不引入后台探测或外部运行时依赖。

## 内置目录与上游操作

Agent Switchboard 自己维护生成器、目录字段和匹配规则，构建和运行直接读取随项目分发的目录。维护时显式导入本地的 models.dev 格式 JSON，记录来源标签和输入摘要，并按本项目支持的 HTTP 协议提取文本模型字段。完整地址和协议共同决定匹配，现有常用供应商保留预设优先级。「获取模型」直接访问当前配置的供应商，成功结果提供上游模型列表的证据。

Codex 新档案以自动判断初始化五项独立操作；切换单项即固定该项，可逐项恢复自动。档案版本 2 必须保存 `automaticOperations` 集合，空集合表示全部手动。旧本地档案只在[配置目录修复](2026-09-23-provider-store-repair.md)的暂存副本中转为当前格式，原有有效开关值完整保留，缺失的自动意图明确写为空集合。普通读取、导入和快照校验消费同一套版本 2 契约。可选接口检查的命令只接受搜索、生成和编辑，模型列表和 Chat 匹配分别由列表读取和编辑器拥有。可选操作与网关共用操作类型和同源 URL，检查只发送 OPTIONS，并用不存在的路径识别通配答复，图片编辑要求明确支持网关使用的 JSON。当前连接变化时清除旧证据，手动值不受检测结果影响。

整包嵌入原始目录的优点是保留上游所有信息；提取所用字段后减少初始加载和重复数据。默认下载固定快照可以简化复现，但会让目录更新依赖特定网络地址；显式导入适用于任意符合 models.dev 格式的本地快照。实际 POST 可以验证凭据、请求体和模型，也可能产生费用；自有路由检查使用上游声明设定默认值，实际账号授权由上游调用决定。

把缺失自动意图解释成手动可直接读取旧文件，但会让当前文件有两种等价编码，也掩盖当前数据的缺项。持久化严格使用一种格式，由现有备份事务对旧本机档案做一次保值转换。
