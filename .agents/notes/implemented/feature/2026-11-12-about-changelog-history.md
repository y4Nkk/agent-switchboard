# Agent Note: 关于页离线历史更新日志

Status: implemented

## Problem

关于页只通过 changelog_section(version) 读取当前运行版本，无法查看旧版本；商店渠道提前返回更新说明，连当前日志也不可见。读取失败被转换为空并隐藏入口，无法区分没有记录与资源读取失败。用户要求在关于界面显示历史版本日志。

## Decision

CHANGELOG.md 继续作为唯一随包分发的数据源，不连接 GitHub 或维护第二份历史。changelog.rs 一次读取本地资源，按现行版本标题边界返回类型化数组 { version, date, notes }；只包含有正文的已发布 SemVer 段，排除 Unreleased，日期为 ISO 日历日期或 null，不推算日期。正文保持原 Markdown，由共享 MarkdownContent 渲染。文件读取或格式失败使用 CommandError 明确返回，空数组只表示没有已发布记录。

版本与日期使用项目已有 semver/chrono 校验，重复版本拒绝返回部分清单；代码围栏中的版本示例不作为边界，保留正文首行的 Markdown 缩进。标题与正文解析只由 Rust 持有，前端不再截取第二份文档。

关于页在软件更新下方独立提供「历史更新日志」，GitHub 与商店渠道共用。默认收起，展开后按需加载，使用共享 Select 切换版本，默认当前版本（若文件中没有当前版本则选择文件首个已发布版本），标明当前版本及发布日期；一次只渲染一个正文。关闭披露后由共享 Collapsible 释放加载组件，迟到结果不更新卸载组件；失败提供重试，空记录有明确文案。远程候选版本说明继续留在下载进度下方。

完整删除 changelog_section/getChangelogSection/useCurrentNotes、旧当前版本披露和对应词条，同批更新原生命令注册、浏览器开发分发、前端类型、直接消费者与解析用例。新旧命令不并存，不增加兼容读取或缺失资源的路径回退。

## Related decisions

- [当前版本段落渲染](../../implemented/feature/2026-10-14-changelog-section-display.md)部分重叠：保留唯一随包文档、共享 Markdown 渲染和外部链接规则；本篇取代单版本读取及失败时静默隐藏的决定。
- [可取消更新下载](../../implemented/feature/2026-11-04-cancellable-update-download.md)继续拥有候选和下载生命周期；历史日志不是更新任务来源，不改变商店渠道行为。
- [共享折叠原语](../../implemented/architecture/2026-10-14-unified-collapsible-primitive.md)继续拥有披露、键盘语义和内容卸载。
- 其余检索命中的版本管理、发布表格、标题栏及路由笔记不拥有应用自身历史日志，无同主题提案需要处理。

## Alternatives considered

- 前端直接加载整篇 Markdown：接线少且保留所有格式，但会把 Unreleased、文档导言和全部长正文一起塞入关于页，无法复用当前版本标记及只渲染所选版本的界面。
- 按 GitHub Releases 在线分页：可读取未包含在当前安装包内的新历史，但会引入联网、限流、渠道和第二份日志来源；本功能需要离线查看随包历史，新版本仍由原更新检查拥有。
- 保留单版本命令再增加历史命令：旧页面可以少改，但同一资源会有两套解析和错误含义；用唯一数组契约同时覆盖当前与历史版本。

## Verification

- 源码核对资源路径、序列化数组、Tauri 注册、浏览器开发分发、前端类型与关于页消费者；搜索确认旧命令、读取函数、当前版本披露及词条在 src/src-tauri/scripts 无残留。既有随包资源映射保持原所有者，没有新增依赖或路径回退。
- 隔离 Vite 预览直接挂载真实 SettingsPage/ChangelogHistory/Select/ReleaseNotes，使用当前文档生成的 30 个已发布版本快照模拟命令响应。默认标记并选中 v0.3.20，切换至 v0.3.17 后日期为 2026-11-10、正文匹配旧版，列表中没有 Unreleased；这不证明 Rust 解析与原生读取已运行。
- 商店渠道仍可展开历史；模拟读取失败显示具体原因，「重新读取」后恢复版本选择；空数组显示无已发布记录。英文界面显示 Release history。截图保留历史版本选择器、日期及 Markdown 正文。
- 解析用例随新契约更新，覆盖顺序与日期、相似版本、未发布排除、围栏中的伪标题、正文缩进、空记录、无效元数据与重复版本；按仓库要求仅保留测试代码，未执行 Rust 编译、类型检查、生产构建或自动化测试。
- 迟到结果由 effect 清理标志拒绝，披露关闭后读取组件由共享 Collapsible 卸载；这两条生命周期按源码核对，未做延迟响应的运行验收。

## Consequences

当前与历史版本共用一个读取契约和查看器，两种渠道都有离线入口，失败不再被误当作空记录；代价是每次重新展开会读取一次随包文本，只保留展开期间的清单与一个正文。只能查看当前安装包自带的历史，不能声称已包含发布后的新版本。Rust 与真实资源路径尚未编译运行，隔离前端预览不能证明原生命令成功；自动化解析用例已更新但未执行。
