# Agent Note: 扩展库与市场的操作布局

Status: implemented

## Problem

分类、搜索和更新分散在扩展库、市场和更多菜单中。市场使用两个全页框架，提交按钮离搜索框较远。批量启停与删除常驻，与日常查找和配置争夺操作空间。

## Decision

扩展库和市场共用工作区及 Skills、MCP 分类导航。库内筛选按类别保存，市场分类首次查看时挂载，在返回扩展库或编辑期间保留查询、结果和用户已提交的读取。搜索提交紧邻输入，更新检查直接位于库工具栏，空库可直接打开对应市场。批量启停进入「更多」，条目显示全分类范围和已启用数量。删除由「部署与诊断」承载。编辑和本机扫描继续使用各自的编辑框架，写入仍通过现有确认与事务。

## Alternatives considered

保留两个全页市场可沿用返回栈和编辑页骨架，切换分类时需要换一套导航，搜索输入和提交分处页面两端。

批量按钮常驻可直接启停并展示范围，占用库内搜索行。将明确的全分类范围和数量放进菜单项，为更新检查腾出位置。

## Consequences

市场内容在扩展工作区存续期间驻留，远程请求由用户提交触发。执行批量启停多一步打开菜单，具体的操作范围在选择前可见。
