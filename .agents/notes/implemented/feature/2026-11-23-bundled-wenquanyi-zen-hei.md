# Agent Note: 随包提供默认界面字体文泉驿正黑

Status: implemented

## Problem

主窗口和托盘需要在机器没有安装文泉驿正黑时也能使用它。默认字体必须在首次离线启动时可用，应用偏好中的已保存字体名也要继续有效。

## Decision

主窗口和托盘通过共享样式加载文泉驿正黑 0.9.45 的比例字面 WOFF2。Rust 设置构造和偏好加载前的 CSS 使用相同的字体名称，设置列表始终提供该字体，并支持中英文检索。字体在首次离线启动可用，系统字体枚举仍服务于用户选择。已保存的字体名继续按原值读取。Noto Sans SC 仍作为随包选项，沿用[有界资源笔记](../architecture/2026-10-14-bounded-local-resources.md)中的 WOFF2 子集生成方式。

上游比例字面的简体、繁体和英文字族名在展示时解析为同一个随包字族。设置列表合并同款字体，三个名称均可搜索。已保存的本地化名称直接在渲染时解析，保留偏好文件原值。

对应源归档、转换脚本和许可证作为安装资源随 Tauri 和 MSIX 一起分发，位于 `licenses/wqy-zenhei/`。字体转换仅用于更新受版本控制的资产，开发和构建沿用现有前端入口。

## Alternatives considered

- 首次使用时下载可以减少初始安装包体积，并让系统已安装同款字体的用户跳过下载，但离线启动、下载失败和来源变动都会影响默认排版。
- 随包直接使用上游 TTC 可省去转换并保留全部字面与位图，但桌面 WebView 只需要比例正黑的轮廓字形，单字面 WOFF2 的加载内容更小。

## Consequences

字体资源约 4.4 MiB，源归档与许可证约 8.9 MiB，实际安装包增量取决于压缩。应用代码保留原字重标记，文泉驿正黑的粗体由 WebView 合成。

源归档的 SHA-256、许可证原件和 WOFF2 字符映射均已核对，转换保留 42,285 个映射字符。Edge 打开使用共享样式的本机样张时，默认字体为 WenQuanYi Zen Hei，资源状态为 `loaded`。安装产物与各平台 WebView 的渲染由打包验收覆盖。
