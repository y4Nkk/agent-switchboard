# Agent Note: 跨供应商路由、工具历史与响应还原的一致性

Status: implemented

## Problem

Codex 工具调用历史在按会话统计调用 ID 后，从全局顺序列表取回记录时遗漏会话约束，同名响应 ID 还共享存储键。没有会话标识的请求也共享匿名历史。备用供应商编辑只更新磁盘档案，当前故障转移队列仍持有旧认证、端点和模型映射；Claude 活动档案的候选构造也重新读取旧存储。xAI 原生 Responses 另外解析 SSE 分片，未满一帧就返回 EOF；WebSocket 没有接入对应响应还原。

## Decision

模型路由的图形编辑与原保存事务的显式 save / activate 意图由[图形化模型路由](../architecture/2026-10-26-graphical-model-routing.md)拥有；本篇继续拥有请求认证、依赖快照、恢复和响应转换，不保留旧运行参数中的路由表单。

- 工具历史以明确的会话标识和响应 ID 共同索引，缺失会话标识不进入共享历史；按调用 ID 补全也只扫描当前会话，歧义不猜测。
- Codex 与 Claude 的供应商保存识别当前故障转移依赖，复用现有预览、确认、档案前像和执行器事务，提交时更新活动所有者的候选快照。保持主供应商身份，失败回滚，恢复从现有日志重建。
- 保存准备绑定候选的有序修订，队列顺序、端点或档案身份变化使旧预览失效。Claude 活动档案及其候选使用同一份准备后的档案；客户端文件内容相同的恢复分支仍发布已确认的候选快照，不能仅靠文件哈希推断运行时已更新。
- 原生 Responses 的上游差异仅由现有供应商适配模块确定；JSON 与完整 SSE 事件共用同一个值还原函数。SseTranscoder 是 SSE 分帧的唯一所有者，HTTP 和 WebSocket 共享它；删除额外 reader、字节分帧还原及旧调用点。
- xAI 是模型供应商而不是客户端。本次保持 Codex、Claude Code 两个客户端范围和现有上游支持，不添加供应商选择开关或过渡格式。

## Related decisions

[供应商诊断与写入边界](../../implemented/bug-fix/2026-10-13-provider-diagnostics-contract.md)部分重叠：保留其档案、认证和执行器所有权，本篇补充运行中候选快照和响应还原边界。按工具历史、xAI、跨供应商与故障转移检索的其他笔记没有同主题决策，无需取代或归档。

[协议转换边界补强](2026-10-28-protocol-boundary-reinforcement.md)拥有 Chat 推理参数语义、空历史和 schema 预检，以及两个客户端共享的 Moonshot 请求修补；本篇继续拥有会话隔离与 Codex 原生 Responses 响应还原，不将 Codex 私有载体适配推广到 Claude。

## Alternatives considered

- 修补额外 SSE reader 并在 WebSocket 再套一层，改动更小；但留下重复分帧、重复缓冲及两条响应还原路径，故直接复用已有完整事件解析。
- 保存后尽力刷新备用路由，能避免客户端文件写入；但刷新失败会使已保存档案与运行时分叉，也绕过了对活动行为变更的预览和恢复，因此沿用保存并应用事务。
- 无会话标识时按全局唯一调用 ID 补全，可以维持匿名请求的便利；但唯一性不构成会话所有权，供应商重复 ID 会造成串用，因此要求完整可见 input 或明确会话标识。

## Regression coverage

- 回归用例覆盖同响应 ID 跨会话、同调用 ID 跨会话、同会话歧义、匿名历史，以及合法显式续接。
- 两个客户端的备用档案保存、Claude 活动档案保存、确认失败、过期队列预览和客户端文件不变时的中断恢复均有隔离临时目录用例，检查实际转发读取的候选身份、认证、模型映射和主供应商。
- 原生事件跨任意分片、CRLF、UTF-8、多行 data 与不完整结尾都有明确处理，HTTP/WebSocket 的工具名称及完整参数一致还原；其他上游保持原内容。
- 共享 JSON 出口用例覆盖工具名称与整数参数还原以及供应商额外字段保留。
- WebSocket 出口回归直接执行生产响应中继，解码实际生成的帧，并检查下一轮工具结果重放所用的连接内缓存；完整 JSON、逐字节 SSE 和残缺终止事件均需覆盖，不能只证明公共转换函数被调用。

## Consequences

删除 NativeRestoreReader、wrap_native_sse_reader、restore_sse_bytes 和旧的独立 JSON 还原入口，不维护第二套分帧器或 WebSocket 专属响应转换。NativeResponsesDialect 只表达当前标准与 xAI 两种上游拼写，不新增客户端、持久格式、兼容读写或过渡开关。

保存候选改为现有保存并应用事务，需要预览和确认；代价是队列在预览后变化必须重新准备。正在执行的请求继续使用接受时的不可变快照，后续请求读取新快照。缺失会话标识的短工具续接需要客户端提交完整调用上下文，以消除匿名请求之间的历史串用。
