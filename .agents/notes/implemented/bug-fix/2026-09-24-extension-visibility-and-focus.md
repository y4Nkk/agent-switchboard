# Agent Note: 扩展操作范围与键盘焦点显性化

Status: implemented

## Problem

扩展库搜索行的客户端数量实际上是批量启停按钮，但界面未常驻说明它会作用于当前分类的全部条目，包括搜索结果之外的条目。列表操作默认隐藏，客户端启停仅用品牌图标、颜色与边框表达；全局焦点样式又移除了键盘轮廓。这些状态需要用户悬停或猜测，妨碍快速、安全地管理扩展。

## Decision

扩展库将批量按钮的动作、已启用数量和当前分类全部的作用范围直接显示在搜索行；搜索时额外写明搜索外条目仍受影响，批量执行范围保持原有契约。列表始终显示「部署与诊断」文字动作及删除入口，有可用更新时显示更新。客户端行控件直接使用共享 Checkbox 的名称、勾选、部分选中和未选中状态，MCP 客户端选择使用同一组件；控件接入与旧样式移除由[共享控件笔记](../architecture/2026-10-24-extension-shared-controls.md)拥有。

「扫描已有扩展」与「查找新 Skills」分别标识读取现有客户端配置和查找待安装内容。来源控件、结果和仓库管理共用一个内容面，内部由间距、对齐和单层浅灰分组组织。导出便携包使用独立的导出图标；旧的悬停显隐样式与客户端专属强调色令牌不再保留。

键盘焦点在共享根样式中获得可见的行动蓝轮廓。视觉隐藏的单选与复选输入由其可见外层承接焦点轮廓，其他控件使用同一 `:focus-visible` 规则。指针焦点不显示轮廓。

## Alternatives considered

- **把批量操作移入「更多」菜单**：能进一步减少搜索行控件，但会增加常用批量启停的步骤，也无法直接展示操作范围，因此保留原入口并写清动作与范围。
- **只在扩展页补焦点样式**：改动范围较窄，但全局规则仍会压掉其他页面的键盘焦点，造成共享控件表现不一致，因此在根样式恢复焦点可见性。
- **来源表单和结果各用一张卡片**：能明确区分阶段，但重复边框会拆散同一查找任务，因此使用一个内容面，以空间分组衔接表单与结果。

## Consequences

用户无需悬停即可识别批量作用范围、客户端状态和行操作；键盘用户能看见当前焦点。搜索行在空间不足时会换行，扩展表格保留必要列宽并在更窄的内容区横向滚动。全局焦点轮廓会出现在其他页面的键盘操作中，属于同一可见性规则。
