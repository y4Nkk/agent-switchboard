# Agent Note: 查询结果与额度状态分离

Status: implemented

## Problem

用量脚本同时提取上游事实并决定查询成败。余额耗尽被某些模板抛成执行异常，缓存持续展示旧余额。把官方端点接管到 Rust 只修复单个供应商，并绕过用户提取器，无法建立通用业务边界。

## Decision

持久化只验证核心当前查询字段；脚本只在查询测试或实际执行时运行。初始化或执行资源失败不能反向判定配置文件损坏，这一边界和真实未改动配置的调度暂停对照由[配置读取不执行用量脚本](2026-11-13-config-read-executes-usage-script.md)拥有。

所有查询按同一流程处理：HTTP 状态校验、JSON 解析、配置的事实提取、业务读数归一化、成功缓存。业务层不识别供应商名称、地址、上游字段或异常文本。脚本输出输入契约 `UsageReadingInput`，声明式查询构造同一输入；只有业务归一化器生成展示与缓存契约 `UsageReading` 的 `availability`（available / exhausted / unavailable / unknown）。套餐有效性 `isValid` 与失效说明 `invalidMessage` 是提取输入，不能作为查询失败；它们不进入归一化输出，避免两个状态源。

明确不可用优先于数字耗尽；存在非正剩余量或已用达到非负总量是耗尽；正剩余或明确有效是可用；只有部分消耗数字时状态未知。缺少全部数字且没有明确不可用事实、非有限数字或非法元数据属于数据错误。负零统一为零，不虚构未知余额。额度不可用仍可返回读数；真实请求、脚本与格式错误仍失败，不从异常猜测零余额。

删除供应商专用 Rust 解析器、地址匹配、提取器绕过和相关测试与文案。模板只做字段转换，删除 HTTP 重复校验及额度不足抛错。列表、明细、托盘、历史使用归一化状态，耗尽读数仍进入历史。脚本输入契约保持现行字段，输出与缓存只接受新契约，不添加别名、双读、迁移或回退。旧的可丢弃缓存按既有无效缓存规则在下一次查询重建。

官方订阅额度具有独立契约，其既有百分比展示适配继续由 `officialQuotaReadings` 持有并映射到同一展示类型；它不进入供应商脚本查询业务链。供应商读数的展示消费者只消费后端状态，不重复判断数字耗尽。

## Alternatives considered

- 官方端点原生接管可以让旧的抛错脚本立刻返回余额，也能严格校验供应商格式；但按地址绕过提取器无法扩展到通用业务，且新增供应商分支，本方案删除该路线。
- 捕获余额异常并转成零余额能保留旧脚本无需修改；但异常不携带可信读数，也无法可靠区分真正执行错误，因此不使用文本匹配或静默恢复。已有脚本若抛异常，必须按事实输入契约修正，业务层不能推断未返回的数据。

## Superseded decisions

本决定吸收并删除本轮尚未提交的两篇供应商局部笔记，保留其独特证据与边界：官方只读查询曾返回 `is_available: false` 与 CNY `-0.00`，卡片仍显示旧的 17.63 CNY；单个用户档案的脚本已经单独修正并在应用 `state/repair-backups` 备份，其他档案字段保持原样。本次不再写真实配置。供应商原生接管路线被放弃；脚本必须返回余额事实、业务层负责额度状态的通用规则接管后续实现。[用量元数据保存](../../implemented/bug-fix/2026-09-22-usage-query-metadata-save.md)的其他字段保持原样约束继续有效。其他主题笔记不受影响。

## Consequences

任意供应商的零、负余额、已用达到总量与明确不可用均进入成功结果，清除历史刷新错误；未知数值不变成零。非成功 HTTP 不调用 extract；脚本异常、无效 JSON、错误读数继续失败。新输出没有旧标志字段，旧缓存没有兼容读取。核心业务代码没有供应商名称、域名或余额异常字符串分支。代价是旧的可丢弃缓存需要按当前契约重新查询；手动刷新档案需要用户点击刷新。输入与输出类型分别表达上游事实和业务结论，后续字段新增必须同步这条转换边界。

## Verification

补充通用脚本与声明式归一化用例，覆盖零、负余额、已用达到总量、未知数值、明确不可用、非有限数值、HTTP 错误先于提取、执行异常保留、输入与输出互不混用、旧缓存拒绝及耗尽更新清除旧错误。余额模板用例覆盖多个供应商的事实提取，业务归一化没有供应商条件。模板中只删除耗尽抛错及重复 HTTP 判断，保留供应商格式转换和上游错误校验。前端静态复核确认列表、详情与托盘从 `availability` 消费状态，没有重新推断数字耗尽。

编译、类型检查与自动化测试按项目规则未经明确要求不运行，补充用例未执行；桌面运行与重新打包未验证。本次只执行笔记校验与差异检查，真实配置和共享数据没有新写入。任意旧脚本抛异常不会被解释成额度耗尽；需修正脚本返回事实，不能从异常中恢复未返回的数据。
