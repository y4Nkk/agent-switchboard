# Agent Note: 会话记录操作层级与长内容布局

Status: implemented

## Problem

项目选择器中的完整路径换行后，相邻选项被菜单布局压缩并叠字；大量相同前缀的目录也难以辨认。批量选择同时显示整理栏和删除栏、重复计数，压缩结果与详情。详情标题承载六个动作，消息收藏按钮仍显浏览器默认边框；片段收藏的筛选与刷新落在内容区，切换页签后操作位置跳变。搜索框可拖高、列表路径任意换行，也让同一视觉行高不稳定。

## Decision

详情中的会话 ID、最近活动、工作目录、恢复命令、保留副本说明及原生历史只读说明归入默认收起的「会话信息」。`SessionDetail` 唯一持有展开状态，复用共享 `CollapsibleSection`；切换到另一会话重新收起，同一会话的消息翻页不重置状态。恢复命令仍在展开后的事实行提供复制。会话标题、恢复与更多操作、需要处理的警示和操作结果继续常显；页头筛选、左侧列表及消息目录保持原有布局。详情滚动面的非正文直接子项统一保持自然高度，正文独占剩余弹性空间；短窗口装不下时沿用详情滚动面，不用信息块私有的收缩补丁。折叠释放的空间由现有正文弹性布局接管，不增加固定高度或页面级滚动。折叠挂载和键盘可达性遵守[共享折叠原语](../architecture/2026-10-14-unified-collapsible-primitive.md)。

筛选行的尺寸与换行由 `session-library.css` 唯一拥有：搜索表单、时间选择、双列日期、标签和置顶直接参与同一条弹性行。共享 `Input` 和选择器的外观与标准 40px 高度由 `field-controls.css` 拥有，从 `forms.css` 按控件职责抽出；原生单行输入不从页头祖先继承弹性基准，多行文本仍使用自身内容高度。日期列宽只定义一次，不用输入框高度覆盖补偿布局错误。日期校验由 `SessionOrganizationFilters` 派生一次，错误提示作为筛选行的独立整行，不参与日期列宽或控件对齐。搜索文本区使用独立布局类，保留多行草稿与提交语义；简短提示来自双语词典，不用隐藏溢出裁切提示。共享分页只拥有内部排布，表格场景的外部间距由表格相邻关系拥有，会话列表继续由容器 gap 排布。

项目菜单保持单行选项，名称优先显示目录末段，完整路径用悬浮提示获取；项目键仍由客户端与原始目录组成。选择模式仅保留一条上下文工具栏，计数、选本页、置顶、取消置顶、标签、删除和退出都由它拥有；标签编辑按需展开。会话与收藏共用页头筛选和刷新位置。详情标题突出恢复操作，导出、整理、置顶和删除进入更多菜单；整理使用已有标准弹窗，别名和标签编辑不再把正文推到首屏以下。恢复命令作为事实行保留复制入口。全部项目视图中，连续的相同项目结果只在组首显示一次可点击的目录；选定项目时不重复显示该目录。主页面固定在视口内，列表和正文各自滚动。列表、消息与空态统一截断、边框、触控目标和对齐。单条删除使用单条确认文案，收藏筛选同步约束右侧详情。此决定接续[项目筛选与结果布局](2026-09-24-session-layout.md)，保留项目筛选位于结果列表顶部的双栏结构。

## Alternatives considered

- 同时收起页头筛选与详情事实，能释放更多高度；但筛选属于持续可达的检索入口，本次阅读空间问题集中在详情事实区域，因此只折叠这块信息。
- 只压缩事实行间距，可让全部信息免点击可见；但会话 ID、长路径和恢复命令仍持续占据多行，正文依然只能使用剩余高度，因此使用按需展开。
- 在日期输入上强制高度、禁止增长，改动最少，也能立即修正截图；但祖先错误的弹性基准仍可影响其他纵向字段，尺寸在两处定义，因此删除祖先规则并由日期网格拥有列宽。
- 保留长搜索提示并禁止换行、隐藏横向溢出，可保持现有文案；但窄搜索框会裁掉提示且引入横向内容裁切，改为词典提供简短提示，实际多行查询保持可滚动。
- 只给现有项目菜单加高度和换行规则，改动最小；但长路径仍会让每项高低不同，大量测试目录的共同前缀也遮住识别信息。
- 保留两条批量栏并缩小按钮，可减少局部拥挤；但重复计数、上下分散和选择态占用两行的问题仍在。
- 将详情所有动作继续常显并靠自动换行适配，发现成本低；但不同标题长度会改变操作位置，窄详情列无法形成稳定扫描锚点。
- 保留行内整理表单并只压缩字段间距，不需额外弹窗；但长原标题仍会推走阅读区，列表与正文不再共享稳定的可见高度。
- 每条结果都保留项目快捷按钮，可从任一项直达项目；但相同目录在连续结果之间反复占一行，目录选择器与详情也已提供项目入口。

## Consequences

- 详情事实不再常驻占据多行；查看或复制会话 ID、目录和恢复命令需先展开一次。Codex 与 Claude 共用同一信息折叠入口，不新增持久化偏好或重复事实来源。折叠与翻页的真实桌面效果尚未验证；本次依仓库限制只检查差异、引用及笔记结构，不运行编译、类型检查或自动化测试。
- 日期错误提示独占筛选反馈行；正常态与错误态共用同一排布，不维护旧类名、兼容选择器、第二套筛选组件或迁移开关。
- 标准分页的换行规则归共享样式；备份、雷达历史和运行日志的表格到分页间距保持原值，会话列表无需局部抵消分页外边距。
- 项目选择器不再靠任意换行展示全路径，列表行高稳定；完整路径仍在提示中可查看。所有项目选择键和后端筛选契约保持原样。
- 批量栏只显示一次计数和一次删除入口；整理上限 200 条只约束整理动作，删除仍走原确认流程。退出选择模式会卸载标签草稿。
- 更多菜单增加一步点击，但有键盘可用的独立菜单项；单条删除和批量删除分别显示对应确认文案。收藏筛选后，右侧不再保留筛选外条目。
- 整理表单打开时由标准弹窗承载，长原标题在弹窗内截断并保留完整提示；导出多一步点击，换取标题可读宽度。项目组首仍可一键筛选，连续结果的目录不再重复。
- 依仓库验证约束，本次不运行编译、类型检查或自动化测试；代码静态检查与笔记结构校验可覆盖引用和文档一致性，运行时视觉效果仍需下一次获准构建后目视核对。
