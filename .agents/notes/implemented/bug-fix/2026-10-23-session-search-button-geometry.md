# Agent Note: 会话搜索按钮的共享尺寸归属

Status: implemented

## Problem

会话搜索栏高 40px，内部图标按钮也采用 40px 最小高度，按钮底色越过输入栏内部边界。共享按钮通用规则的 `:not()` 增加了优先级，使图标变体的零内边距不能覆盖文字按钮的内边距。页面直接重写宽高、最小高度和内边距虽然能修正显示，却重复拥有按钮几何。

## Decision

Button 通过 standard / compact 尺寸表达现有 40px / 32px 控件契约，尺寸规则由 buttons.css 唯一拥有。通用按钮规则使用低优先级的排除条件，变体能够正常覆盖通用几何。会话搜索显式采用 compact，页面只保留排列与右侧留白，移除重复的尺寸及内边距覆盖。搜索行为、可访问名称和禁用语义保持原有入口。

提交按钮的说明通过共享 Tooltip 在输入栏下方显示，与按钮保持间隔；删除浏览器原生 title 提示。页面只对 Tooltip 锚点定义不收缩和右侧留白，不再对子按钮重复定义几何。提示碰撞处理、禁用命中和聚焦行为继续由共享 Tooltip 拥有。

检索活跃笔记没有同主题尺寸所有者。[Tooltip 锚点笔记](2026-10-14-tooltip-dismissal-anchor-contract.md)继续拥有提示开闭和锚点命中，不涉及本次按钮尺寸。

## Alternatives considered

- 保留页面局部尺寸覆盖：影响最小、修复直接；但页面继续重复定义共享按钮的尺寸和内边距，通用样式的优先级错误仍在，因此不采用。
- 给搜索容器添加 overflow 裁剪：无需改变按钮契约即可限制底色；但按钮仍大于容器内部空间，且焦点轮廓也可能被裁切，因此不采用。

## Consequences

搜索按钮采用共享 32px 尺寸，40px 输入栏内部保留上下空间及右侧 4px 留白；原有页面宽高、最小高度和内边距覆盖被移除。共享标准图标按钮的零内边距正常生效，不增加裁剪、兼容类、回退或第二套搜索入口。

代价是通用规则降低优先级后，其他按钮已声明的变体和上下文规则也能正常生效，需要关注这些现有声明的实际显示。默认 standard 尺寸仍为 40px，compact 使用既有 32px 令牌，不增加新的数值来源。

## Verification

静态检查确认搜索按钮显式消费 compact，页面只定义 flex 和右侧留白，按钮尺寸与图标内边距由共享规则拥有。执行笔记结构及差异检查；按项目指令不运行构建、类型检查或自动化测试。实际桌面悬浮、焦点和其他按钮视觉回归尚未验收。
