# Agent Note: 操作日志只接受当前契约

Status: implemented

## Problem

客户端占用错误已改为结构化消息，但读取任务日志仍接受 version 1 并隐式转换旧字符串。用户要求本次需求无兼容、无过渡；该旧读取分支不属于当前错误契约。会话归属预览还按每次 ID 永久保存文件，重复预览积累已失效的完整清单。

## Decision

客户端更新日志由 task/journal 唯一拥有，只接受 version 2 和当前 UpdateTask，不在读取时升级或重写旧结构。旧版本、无效错误结构和超限输入明确报错并保留原件；不把未知任务当作空任务继续安装。保存复用现有持久原子发布边界。

Codex 会话归属由 provider_transfer/journal 唯一拥有一个 preview.json，新预览原子替换旧预览；提交 ID 必须等于当前预览 ID，过期或被替代的预览不写历史。正式操作仍按 ID 保留完整备份和当前恢复记录，不把预览文件当作备份。暂存准备失败且尚未发布恢复日志时，清理本次新建备份目录；清理失败保留具体位置和错误。

## Alternatives considered

- 读取旧日志时一次性转换，能够保留先前版本的未完成任务并减少用户操作；但它仍让普通读取接受旧契约并产生隐式写入，违背本次明确的无兼容要求，因此删除，不新增第二套修复或过渡入口。
- 每次预览永久留档，便于按 ID 排查所有预览；但预览没有执行事实且会过期，完整清单持续占磁盘，正式操作已保留完整依据，因此仅保留当前预览。

## Consequences

删除旧格式升级函数、字符串转换分支与对应升级夹具，正常读取不写任务文件。夹具改为确认旧版本、未知结构和字符串错误被拒绝且原件字节不变；当前两端的结构化错误继续共用持久契约。新预览使旧 ID 失效，准备失败仅删除本次经绝对位置复核的新建目录，不删除正式操作备份。

所有直接生产者、消费者和产品说明使用当前契约。验证仅包括笔记门禁、静态差异及残留引用检查；自动化夹具、编译、原生更新和真实会话写入未运行。

旧版客户端更新日志不会自动恢复，原件保留且具体错误阻止安装继续。该变化仅在代码中实现，本次不转换或删除用户真实任务日志、会话或配置。正式操作备份继续保留，磁盘占用由实际确认的操作数量决定。
