# Agent Note: 圆角单一 token 契约（尺度、角色与形状例外）

Status: implemented

## Problem

用户要求对全应用的按钮圆角值、边框圆角值做统一设计接入。全库审计（140 处 `border-radius` 声明逐点归类）显示 tokens.css 已是事实上的尺度拥有者、136 处已消费 `--asb-radius-*`，但契约不完整：`.asb-codex-reset-badge` 硬编码 `999px` 绕过 pill token 形成双路径；`--asb-radius-container`（32px）定义后全库零消费；三处亚尺度数据墨迹字面量（图表柱 1px 顶角、10px 热力图格 2px、骨架行 `calc(--asb-radius/2)`）归属不明；DESIGN.md 只有一句尺度罗列，没有角色表、按钮规则与例外清单——新控件该用哪一档、哪些字面量合法，无可判定依据。

## Decision

tokens.css 是唯一圆角值拥有者，尺度收窄为六档并按角色消费；DESIGN.md 拥有角色表与例外清单，同批完整化。

- **尺度与角色**：12px 基础控件（按钮、输入、菜单项、表格、卡片、行内控件）为默认基准，由共享 `.asb-btn` / `.asb-input` 等基线拥有、消费者继承，不得本地另写数值；16px 中型卡面（偏好预览卡、供应商行缩略块）；20px 导航项；24px 内部信息组与弹层；28px 面板与工作区；pill 只保留给形状即语义的元素（状态胶囊、开关轨/滑块、计量与进度条、圆点、chip、滚动条拇指及刻意胶囊动作）。32px 档删除——零消费的死档位，将来真需要 32px 表面须先改 tokens.css 与 DESIGN.md 条款。
- **按钮规则**：按钮圆角由共享按钮基线（12px）拥有；胶囊是按钮的形状语义变体而非尺度档。新增胶囊按钮须有形状理由（浮动控件、chip、表单提交类主行动）并落在 buttons.css 或其同责文件。
- **形状例外（合法字面量，不占尺度、不新增档位）**：`50%`（正圆：圆点、滑块拇指与刻度）、`0`（贴边直角：表格单元格、编辑器脚注）、`inherit`（计量条填充跟随轨道）、亚尺度数据墨迹微圆角（图表柱 1px 顶角、热力图格 2px、行骨架 `calc(--asb-radius/2)` 比例半值）。三者物理上低于 12px 尺度域，属比例几何或贴边语义，与 `50%`/`0` 同类。
- **契约域外（审计已归类，不接管）**：原生合成层的窗口特效圆角（`tauri.conf.json` `windowEffects.radius`，静态 JSON 无法引用 CSS 变量，由原生窗口配置拥有）；自包含内容工件的内联样式（codex 探针 `pelican-reference.html`，整体分发的内容文档，不消费应用 token）。
- **本次代码改动**：`.asb-codex-reset-badge` 的 `999px` 接 `var(--asb-radius-pill)`（渲染不变）；tokens.css 删除 `--asb-radius-container` 并把形状注释改为完整所有权声明（尺度、例外、「不得本地定义」）；`.asb-btn-plus`（新建供应商）与 `.asb-editor-submit`（编辑器提交，供应商保存与用量查询共用）删除胶囊覆写，回落共享 `.asb-btn` 基线 12px——用户当日先后指出这两处动作按钮未接入标准形状。

圆角尺度的最初所有权事实见[桌面工作区视觉与交互所有权](2026-10-13-desktop-workspace-uiux.md)；本篇接管尺度的档位构成、角色映射与例外判定。

## Alternatives considered

- **三个亚尺度字面量各自立 token**（如 `--asb-radius-micro`）：最强理由是满足 tokens.css 头注释「radius 值只能在此定义」的字面读法。否决：各只有单一消费点，属比例/数据墨迹形状语义，立三个一次性 token 是尺度膨胀——与刚删除的 32px 死档位是同一类错误。
- **胶囊按钮统一回 12px 标准**（参考外部项目「普通动作按钮统一 14px、胶囊只留状态」的条款）：最强理由是「普通按钮一个形状」更严格。否决：本项目的胶囊按钮（编辑器提交、新建供应商、回顶、会话标签 chip）各带明确形状理由且已成体系，DESIGN.md 现行条款明确「按钮和输入继续遵守基础组件定义」；本任务是接入统一而非视觉重设计，迁移胶囊属新设计决定，需用户明示。同日用户先后指出新建供应商与编辑器提交未接入，两者已迁回标准圆角并从胶囊动作名单移除；仍保留胶囊的动作仅回顶浮动控件与会话标签 chip。
- **骨架行改固定 6px 字面量**：最强理由是消除 calc 表达式。否决——calc 已消费拥有者 token，尺度调整时骨架自动跟随；换成字面量是切断跟随的倒退。

## Consequences

收益：140 处声明全部可判定（token 消费或点名例外），硬编码双路径清零，死档位删除，新控件圆角有唯一答案。代价：32px 不再是合法圆角值；tokens.css「唯一拥有 radius 值」按例外清单读——亚尺度数据墨迹与形状语义字面量留在消费点。验证：全库 grep 审计（含单行规则与 `50%`/`0`/`inherit` 逐点归类，`--asb-radius-container` 全库仅剩定义即删）；徽章改动为纯 CSS 值替换（999px→999px 渲染不变），`.asb-btn-plus` 与 `.asb-editor-submit` 是可见形状变化（胶囊→12px 圆角矩形）；按工作区规则未主动运行 typecheck/test（用户未要求）；`npm run verify-notes` 通过。
