# Agent Note: 图形化模型路由与单一保存事务

Status: implemented

## Problem

Codex 默认子代理模型藏在供应商运行参数中，新建档案因尚无 ID 而错误选择其他档案或无法指定模型；恢复运行参数默认值也未清除独立路由引用。网关页只能观察连接，用户需要在多个页面理解主模型、子代理目标和协议之间的关系。Claude 的模型档位映射缺少与整体调用去向对应的可视化入口。

## Decision

- 「模型路由与网关」是主导航一级工作区，承载唯一的图形化模型路由工作区，以客户端、用途和供应商模型节点表达方案；点击目标节点编辑，键盘和辅助技术消费同一份语义 DOM。SVG 只连接实际节点边界，ResizeObserver 与动画帧随场景卸载清理，不新增图形运行时或依赖。工作区自设置二级分类上移（2026-10-27）：`WorkspacePage` 契约新增 gateway 页并可被「上次访问」记住，设置删除该分类与 `nav.section.gateway` 词条，工作区头部标题改用 `nav.page.gateway`。
- 供应商档案继续唯一拥有模型、Codex subagentRoute 和 Claude 档位映射。选择主供应商加载该档案完整路由草稿；不创建全局路由文件，不复制凭据，不把草稿画成已生效连接。当前应用状态仍由客户端配置与网关快照拥有。
- 既有供应商保存准备显式接收 save / activate 意图。图形工作区用 activate 在一次已确认、可恢复的原执行器事务中保存目标档案并切换到它；普通编辑继续用 save。准备绑定意图、档案版本、配置差异和候选修订，提交重新校验，禁止先保存再独立切换的部分成功。
- Codex 提供主模型和默认子代理节点；自动不保存路由引用，指定先由用户选择供应商和目录模型，不自动选择其他档案第一项。Claude 提供主模型与 Haiku/Sonnet/Opus/Fable 档位映射（2026-10-28 补齐 Fable：契约 `fable_model` 与 `env.ANTHROPIC_DEFAULT_FABLE_MODEL` 早已存在，图形档位列表此前漏列），不伪造逐档位跨档案能力。图形与 `RouteState` 快照的档位集合跟随 `ClaudeModelSettings` 拥有的全部档位，不各自维护硬编码子集。重置在当前图形入口统一恢复路由自动值。
- 移除供应商运行参数中的旧子代理表单与旧 Claude 档位编辑入口；供应商列表提供直达工作区的入口。资料与模型目录仍由供应商页管理，原保存草稿、版本守卫和恢复格式不变。
- 图形节点与检查器直接显示当前模型，目录选择继续复用全局 ModelPicker；Claude 可选模型列表归供应商资料，输入时保留原始换行并向草稿提供归一化模型数组。连接观察在父场景引用提交后启动，避免子组件布局副作用早于父引用而漏掉首次连线。
- 页面离开使未确认的异步预览失效，迟到结果不得在其他页面打开弹层；已确认提交继续完成并刷新应用事实。图形草稿在临时切页期间保留，不新增持久化草稿。隐藏时不渲染确认弹层。
- 准备记录由共享 useProfileSavePreparation 持有：确认前取消、离开或卸载必须通过唯一 cancel_profile_save 命令撤销后端令牌，迟到准备同样释放；确认时先移交给提交，不能把已确认事务当成取消。命令明确携带 profile / codex 契约来源，不保留单独的旧 Codex 撤销入口。撤销失败保留诊断并允许重试，不能只隐藏弹层或等待 TTL 代替用户取消。
- 同一共享所有者提供准备前的生命周期版本与持有校验；普通保存和图形入口均绑定所属工作区，离开后重新进入也不能复用迟到结果。图形入口不再持有第二份生命周期计数。元数据保存拒绝意外的需确认分类时同样撤销对应准备，不遗留未消费令牌。普通保存确认直接复用 PreviewInspector 的警告、差异和备份位置，删除重复展示与退役文案。
- 忙碌时的快捷请求保持待处理，结束忙碌后才消费；明确丢弃或继续编辑仍由现有未保存确认拥有。确认成功后刷新配置快照与网关快照，不等待轮询，也不由前端推断生效连接。

## Related decisions

[网关空间拓扑](../feature/2026-10-12-gateway-spatial-topology.md)继续拥有运行快照与流量聚焦，本篇仅接管配置图与编辑流程，属于部分重叠。[跨供应商一致性](../bug-fix/2026-10-23-cross-provider-route-consistency.md)继续拥有目标认证、候选与恢复，新增显式激活意图复用该事务。[桌面工作区](2026-10-13-desktop-workspace-uiux.md)继续拥有列表布局和页头，不保留两套路由编辑器。检索命中的协议标签与共享折叠笔记仍有独立责任，不归档。

## Alternatives considered

- 只将原表单搬到网关页，影响小且复用现有行控件；但无法直观看到客户端、用途和目标的关系，也保留新建身份问题，因此使用受控节点图和选中节点检查器。
- 前端先保存目标档案再调用普通切换，完全复用现有命令；但切换失败会留下已修改的档案，无法表达一次应用的恢复边界，因此在原保存事务中加入显式激活意图。
- 新建独立全局路由存储可让工作区结构最自由；但会与供应商默认模型、子代理引用及档位映射形成双重所有权并改变持久数据含义，因此继续编辑现有档案事实。

## Verification

- 沿用用户对本次跨供应商及全局 UI 修复的编译、回归授权。全部写入测试重定向 HOME、USERPROFILE、APPDATA、LOCALAPPDATA、CODEX_HOME、CLAUDE_CONFIG_DIR 与临时目录；关闭真实供应商测试并移除继承的模型密钥环境变量。切换测试另使用项目现有 redirect_client_paths 与 tempfile，不读写真实客户端配置。
- 前端生产构建（含 TypeScript）与原生 cargo build --offline --locked 通过。前端 48 项、切换事务 40 项回归通过；原生激活与撤销共 8 项针对性测试验证未修改目标仍需预览确认、两端过期配置保持原供应商及档案前像、新建档案不能直接激活、新路由及实际目标目录在同一事务中保存，以及两端撤销后令牌不可消费且不改动实际配置。网关 121 项与 Codex 核心 63 项沿用上一轮通过结果，相关底层请求转换与适配器代码本轮没有改动。
- 隔离浏览器直接加载当前业务 React 组件与全局样式，以模拟 Tauri 调用通过 30 项交互检查；覆盖深浅主题、宽窄布局、双语、键盘、快捷入口、版本冲突、失效引用、官方登录、Claude 档位、普通保存与图形入口的撤销和失败重试、离开及重新进入后的迟到预览撤销、已确认提交切页继续完成，以及不等待轮询的运行快照刷新。所有外部请求被阻断；界面测试不等同于安装后的原生窗口或真实上游模型验收。
- README、DESIGN 与 changelog 描述当前入口；新截图由相同隔离组件截取，并同步官网的图片、说明与真实像素尺寸，删除旧参数表单图片。

## Consequences

- 收益：路由方案、实际活动供应商与运行快照分别由现有事实所有者提供；用户在一处修改节点并检查真实文件差异。删除旧表单、选择帮助函数、退役文案及重复保存别名，不保留高级开关或旧输入分支。
- 代价：显式激活扩大原保存命令的输入契约，所有调用者必须提供 save / activate；提交仍需重新校验档案、候选队列与实际配置。图形增加 DOM 尺寸观察与帧清理，但没有图形依赖或第二份路由存储。
- 边界：Codex 目标来自已保存且未绑定账号的目录；Claude 档位仍共用所选档案的连接。只有产品明确改变逐档位路由能力时，才重访该边界，不能由图形 UI 推断新能力。
