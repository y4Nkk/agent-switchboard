# Agent Note: 按档案保存用途路由并独立编辑与启用

Status: implemented

## Problem

图形工作区的保存固定激活所选档案，编辑非活动供应商会连同地址和认证一起切换。Claude 档位只有同连接模型字符串，Codex 普通模型映射未强制经过执行映射的网关。

## Decision

供应商档案继续唯一拥有连接、认证、模型和用途方案。页面的编辑档案与当前活动身份独立；保存根据真实活动依赖分类为仅保存或保存并更新原活动方案，永不隐式激活编辑对象。供应商启用沿用显式切换流程，删除保存接口的 save/activate 参数。

[供应商统一编辑](2026-11-13-provider-routing-editor-integration.md)拥有新建 UUID、编辑分区、两个入口共用会话及网关只读总览；本篇的用途结构、独立启用和活动依赖事务保持不变。

Claude routes 是每个用途的唯一事实：null 表示原自动规则，primary 保存当前连接模型，provider 保存明确的 profileId、model 和 oneM。旧档位字符串只在离线升级中转换，不在运行时双读。目标连接不递归执行目标用途方案，显式目标不参加主供应商故障转移。Codex 模型映射强制网关。

保存目标档案须校验所有入站引用，活动依赖在既有预览、前像与恢复事务中同步更新。预览列出编辑对象、活动主供应商与用途去向；本机入口变化与上游变化分开表达。准备后相关档案、客户端配置或依赖修订变化使确认失效。

两端保存持有同一用途目标写锁，请求读取目标持读锁直到完整快照形成，避免使用事务中间态。路由修订绑定连接、模型、凭据和参数，排除端点自动使用时间等元数据；显式目标的连续性密钥消费同一稳定修订。Claude 普通模型名映射只读取本地 Primary 模型，Provider 由用途标识解析；渲染器拒绝含 Provider 用途的直连计划。

Claude 目标模型偏好优先于目标明确全局 effort/cap；源方案的全局客户端生成行为保持原归属，网关不重写已经生成的系统提示。备份快照当前版本为 8，已知版本 7 在离线解码入口完成转换后统一进入当前严格校验。本地升级使用现有 staging、原文备份与恢复机制。

未确认准备的撤销失败保留在释放队列；下一次保存或预览先重试，失败则阻止创建新准备。切页、上下文改变和迟到返回不能使旧准备重新可提交。

## Related decisions

[图形模型路由](../../implemented/architecture/2026-10-26-graphical-model-routing.md)部分被取代：替换其隐式激活和 Claude 单连接边界，保留档案所有权、图形入口和准备生命周期。[跨供应商一致性](../../implemented/bug-fix/2026-10-23-cross-provider-route-consistency.md)继续拥有恢复与候选一致性，本方案扩充显式用途依赖。其余协议与性能统计笔记不属于本次决策。

## Alternatives considered

- 只修正文案和增加警告可最小化修改，但仍把用途编辑和整套供应商切换耦合，不能满足独立编辑与 Claude 显式目标。
- 全局客户端路由能彻底独立主供应商选择，但需要迁移档案模型所有权并重新定义切换含义；当前按档案保存能解决需求且保持既有业务含义。

## Testing

- 两端保存无活动依赖的 B 不改变活动 A；活动/被引用档案更新原活动方案且保持身份。
- Claude 用途和 Codex 子代理使用目标地址及认证，显式目标不回退其他供应商。
- 原 Claude 字段离线升级保留模型、上下文与自动语义，运行时拒绝旧格式。
- Codex 非空名称映射通过网关执行；失效引用阻止保存、删除和提交。
- 聚焦核心、后端事务、升级与前端检查在隔离目录运行，不写真实用户配置。

- 最终 `cargo test --workspace --locked --offline`：990 项通过、0 失败，8 项原有手动/驱动用例按标记忽略。外层隔离所有客户端、用户、应用数据和临时目录，关闭真实供应商测试并移除继承的模型密钥；loopback 检查在允许本机连接的执行环境运行。日志位于 `.tmp/purpose-routing/rust-workspace-final.log`。
- 前端全量 77 项 Node 测试、TypeScript 与生产构建通过；隔离静态浏览器 38 项断言验证独立保存、依赖更新、上下文失效、撤销失败重试、迟到返回、自目标模型选择和中文窄窗口深浅主题，证据位于 `.tmp/model-routing-ui/evidence.json`。

## Consequences

收益：用途选择不再隐式切换主供应商，两端保存和请求消费同一明确契约，无旧字段双读。代价：目标依赖校验与保存门闩增加跨模块约束；官方登录、托管账号和原生云 SDK 保持明确的目标能力限制。不兼容的主连接故障转移候选用途在投影和请求时拒绝。真实客户端采用新配置与本机模拟上游验证属于不同证据，尚无真实账号或原生客户端交互验收。
