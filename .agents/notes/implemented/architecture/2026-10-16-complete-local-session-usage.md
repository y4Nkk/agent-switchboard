# Agent Note: 完整本地会话与按可见页签读取的用量契约

Status: implemented

## Problem

会话目录被当作全部历史，遗漏 Codex 原生历史库；相同逻辑会话的续接文件被首个文件去重丢弃，Claude 子代理未进入读取范围。文本提取器静默过滤代理消息、工具、推理和附件；文件修改时间与注入上下文冒充活动时间和摘要。用量消费统计与原生会话读取没有共同覆盖边界，目录扫描失败、缓存及后台页签生命周期可以把部分结果当作完整结果展示。供应商保存错误删除额度历史，额度采样按条数裁剪，日志先截取后筛选。

## Decision

本地会话目录拥有 Codex 与 Claude 的全部当前原生来源及逻辑身份。Codex 原生数据库提供历史身份、当前记录与持久化会话内容，原生 rollout 提供协议记录和真实用量事件；Claude 主记录与子代理记录均进入当前读取契约。数据库读取失败、记录缺失、未完成尾行和不可解码内容都有明确结果，不通过旧读取入口或伪造默认值掩盖。已有用户会话、凭据与业务数据不被开发验证改写。

一个消息解码器负责所有受支持的当前记录、稳定身份、原文及结构化内容呈现。会话搜索、详情、收藏、复制和导出消费同一读取器；分页限制一次传输和展示，不限制总记录范围。工具、推理、代理消息、附件及未知结构均可阅读，无法解密的内容明确标记。活动时间取原生事件，摘要取真实用户请求；主会话与子代理身份不互相覆盖。

用量按当前选择的今天、近七天、近三十天或全部范围汇总真实调用记录。Codex 只读取 token_usage_record 及压缩检查点保留的同类调用，以 thread_id、session_id、response_id 确认归属与去重，模型由对应 turn_id 的上下文确认；Claude 以供应商消息身份合并流式最终用量。压缩检查点没有原调用时间时只计入「全部」，后续找到原始调用则补充原时间而不重复累计。未保留调用记录的会话只说明覆盖缺口；上下文 token_count、原生 tokens_used 与继承累计值不进入消费统计，不能据此伪造日期、模型或消耗。快照由当前契约及范围标识，失败保留上次结果并安排重试。

消费、额度和雷达三个页签仅在当前工作区及对应视图可见时读取、更新展示和刷新。隐藏保留草稿与导航，不持续运行无效查询；正在执行的真实雷达任务继续由后端任务所有者管理。页签与时间范围都是唯一的读取条件，删除 opened 状态冒充 visible 的路径。消费缓存带本机日期与时区边界，刷新期限不跨过本机零点；额度历史响应带实际查询身份，切换供应商时不短暂显示另一来源的旧曲线。

供应商保存与删除只失效派生缓存，不删除历史。额度历史由 SQLite 唯一拥有，不按年龄或采样数裁剪；图表从全部跨度中选择最多 720 个原始点，同时返回完整数量与起止时间。启动事务导入旧 JSON 的每个有效点，提交后按原文摘要复核并归档原件；失败保留材料，重启只完成已导入原件的归档，不重复导入。无运行时 JSON 双读或双写。官方账号变更切换历史代次，旧点保留；供应商历史按当前查询摘要隔离。

Codex 原生登记库与历史库只读。原生消息身份由原生 item 及内容摘要拥有，JSONL 贡献原始协议内容；只合并身份和内容都相同的原生投影，不按消息类型排除原始用户、开发者指令或推理。原始协议可以保留原生投影未保存的字段，两个不同表示均可阅读；重复续接按文件内出现次数的最大值去重，真正重复的无身份原文不会被集合误删。数据库不可读时保留错误并继续读取仍可用的独立原始来源。原始文件的消息身份仍校验完整前缀。读取保持单记录有界，页面仅传摘要及按需正文与图片。原生历史删除交还 Codex，界面禁用该操作并解释归属；Claude 子代理恢复所属主会话。导出不得覆盖源记录或原生数据库。

收藏的当前 SQLite 契约分别保存正文与已读取的图片数据，图片不会混入文本分页或搜索长度。已有 v1 快照在单一事务中保留全部标识、正文和时间并转为 v2，旧快照本就未保存附件，不能重新读取当前原文来改写旧快照。完整复制及 Markdown 导出仅在操作时组合图片，不维护第二份拼接正文。

会话整理目录由 layout 唯一拥有。LocalState 已经交付 state 根，原先再次附加 state 导致双层目录；启动前整体移动原 sessions 命名空间到唯一的 state/sessions，SQLite 日志随目录保留。新旧两处同时存在时保留两份材料并拒绝猜测胜者；运行时不保留旧目录读取。当前进程解析的应用数据目录未发现这两种位置的已有收藏或整理库，迁移边界以隔离夹具留给明确授权后的运行验证。多文件原始会话按真实事件时间合并小型位置索引，单文件仍逐条读取，不把归档目录排序当作时间顺序。

额度历史在当前 SQLite 内拥有迁移就绪状态。原件尚未完成归档或导入失败时，该领域拒绝读写并保留明确诊断，不能继续追加到不确定的历史；重启重试剩余步骤。可选历史失败不会阻止应用启动或隐藏本次成功的真实额度读数，其他会话与配置功能继续可用。

历史数据库以 WAL 隔离图表读取与追加，写入请求完整同步；不能启用该模式时明确报错，不在长历史查询期间静默丢弃新读数。图表计数与采样在同一只读事务中完成，账号代次与采样范围不会混用两个时刻的状态。

材料发布复用同一持久化边界：Windows 请求写穿移动，Linux/macOS 初始化移动使用原生不覆盖操作并同步目标及来源父目录；用户明确选择的导出保留原子替换。未完成迁移只在原件摘要与完整备份复核后进入就绪状态，未初始化存储不得返回空历史冒充读取成功。一个成功供应商响应中缺少数值的窗口不再使其他真实数值整批丢失；业务不可用与数字事实独立，不伪造未知值为零。单条记录超限明确跳过并继续读取后续有界记录，文件后段不可读也保留已经读取的身份和调用事实。

同一真实调用解码器负责会话统计与雷达计量，保留输入、缓存读取、缓存写入、输出与推理事实。删除 token_count 差量、累计回退推算、按时间猜测父归属、累计残差补总数及未接入运行时的 session_sync 模块和派生同步游标表；账本升级保留原请求事实。日志在截取前执行当前筛选，并返回完整筛选总数及读取问题。受影响 API、序列化、夹具、文案和产品说明同批更新，删除被替代的旧入口。

Codex 目录规则对照仓库锁定版本的[原生配置实现](https://raw.githubusercontent.com/openai/codex/rust-v0.155.0/codex-rs/core/src/config/mod.rs)与[路径所有者](https://raw.githubusercontent.com/openai/codex/rust-v0.155.0/codex-rs/utils/absolute-path/src/lib.rs)：用户配置目录中的相对 sqlite_home 按配置目录解析，配置优先于环境变量。相对 CODEX_SQLITE_HOME 依赖原客户端启动目录，控制台不能猜测该目录，因此明确报出覆盖缺口而不读取另一位置。本机保留的客户端历史包含 0.154 至 0.162 alpha 版本，真实调用字段与[当前协议定义](https://raw.githubusercontent.com/openai/codex/rust-v0.155.0/codex-rs/protocol/src/protocol.rs)一致；[原生上下文计数实现](https://raw.githubusercontent.com/openai/codex/rust-v0.155.0/codex-rs/core/src/session/mod.rs)会在额度刷新、上下文估算及满窗口时发出或重写 token_count，故该快照不能证明发生新调用。浏览器开发入口按既有领域机制拆开命令分发，76 个直接命令各保留一个归属。

## Alternatives considered

- 只增加扫描目录或取消分页改动最少，但不能读取原生历史、辨别续接与重放，也不能修复结构化内容和可见性，因此不采用。
- 继续保留两套用量解析器并添加逐项补丁最容易复用现状，但来源身份、去重、错误与范围会再次分叉，因此由一个现行计量读取边界接管。
- 从上下文快照的 last 或累计差量推算调用，可以覆盖没有逐次调用记录的旧文件，看起来数字更全；但快照包含估算、继承与重复通知，无法证明一次真实消耗。保留来源缺口比捏造精确数字更符合当前契约，因此删除这条推算路径。
- 把全部历史和正文一次性送入前端最直接，但内存与 IPC 随历史持续增长，因此保留有界页面和按需正文，完整性在来源与总数层保证。
- 额度历史按小时聚合可以降低磁盘增长，但会丢掉真实采样和重置变化；当前需求优先保留原始事实，回收仍须显式归档。

## Consequences

全部当前来源有明确身份与覆盖结果，旧文件首个胜出和子代理排除路径消失；原生历史和当前 JSONL 内容使用同一消息输出。日期筛选、搜索、复制与导出的覆盖一致。用量范围与当前页签匹配，隐藏读取停止，失败有重试。保存供应商不删除额度历史，日志筛选覆盖原文件全部有效记录。补充续接重放、原生日志缺失、损坏记录、日期范围、Claude 流式用量及子代理、真实调用与检查点去重、快照不参与计量、缓存过期、额度迁移与完整采样、日志过滤的隔离夹具。Windows 发布构建已通过前端类型检查、生产资源构建、Rust release 编译和 NSIS/WPF 安装器封装；包内程序与本次编译结果仅有 Tauri 正式 bundle 标识的三字节差异，更新日志与源文件一致。自动化回归夹具尚未执行，构建证据不能替代真实迁移读写和桌面行为验收。

客户端原生数据库模式可能变化，必须明确报出不支持或不可读，不能静默显示空历史。已经被客户端删除的原始计量分项不能从累计值精确恢复。保留原始额度采样会增加磁盘占用，需沿用可观察的显式维护边界。未经运行验证的源码结果不得表述为桌面验收。
